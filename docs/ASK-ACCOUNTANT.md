# 給會計師的四個問題
> MOTRIX ERP 財務出納模組｜2026-09-23
> 我們正在開發公司內部的傳票與會計科目功能，有四件事想請教。
> **每一題底下都寫了「如果來不及回覆，我們會先怎麼做」。**
> 四題都不會擋住開發 —— 但答案會影響我們現在的預設值，所以想先確認。

---
## 1️⃣ 我們打算用經濟部的《商業會計項目表》當科目基礎，**112 年度版是現行最新的嗎？**

**為什麼問**：我們已經把那份表（112 年度及以後適用版本，共 547 個項目）匯入系統，
當成不可修改的標準科目；公司自己要用的科目另外加。
如果 112 年版之後已經有新版，我們匯入的就是舊的一份 ——
而它**看起來會完全正常**，只是有些項目過時了。

**如果來不及回覆**：我們照 112 年版先做，並在系統裡記下版本號，
日後換版時可以整批更新而不影響已經開出去的傳票。

---
## 2️⃣ **發放獎金時，「還沒發出去的那筆錢」應該記在哪個科目？**

**為什麼問**：我們要做獎金分潤，核定之後、實際匯款之前，那筆錢是公司的負債。
我們查過 547 個項目裡**沒有「應付獎金」**，相近的有：
```
2191  應付薪資
2197  其他應付費用
```
**三種做法**：
```
甲  併進 2191 應付薪資      ⇒ 合規，但獎金和薪資混在一起，報表上分不出來
乙  併進 2197 其他應付費用  ⇒ 合規，但「其他」項目底下東西多，不容易追
丙  自己新增一個「應付獎金」 ⇒ 報表清楚，想確認這樣做在帳務上有沒有問題
```
**如果來不及回覆**：我們先做成**可以切換**的設定，預設用 **2191 應付薪資**
（最保守），確認之後再改，不需要重做。

---
## 3️⃣ **「誰在什麼時候查看／匯出過傳票」這類操作紀錄，算不算會計帳簿？**

**為什麼問**：這關係到**要保存多久、能不能刪**。
我們理解商業會計法第 38 條是：會計憑證至少保存 5 年、會計帳簿及財務報表至少 10 年，
從年度決算辦理終了後起算。
```
若這類紀錄算帳簿  ⇒ 要保存 10 年，而且不能刪
若不算            ⇒ 可以設保留期限（例如 1 年）定期清理
```
⚠️ 兩者的資料量差很多（查看紀錄會每天累積），所以想先確認。

**如果來不及回覆**：我們先把「**誰匯出過**」當成要長期保存的（資料離開系統的證據），
「**誰查看過**」設一年保留期。兩者都可以事後調整保留期限，不會有資料損失。

---
## 4️⃣ **月結（關帳）之後，還可以補登那個月份的傳票嗎？**

**為什麼問**：傳票日期現在可以指定（預設當天），所以 10 月初補登 9 月的帳是做得到的。
我們想知道的是**上限在哪裡**：
```
一旦某個月份結帳完成、報表出去了
⇒ 之後還可以再開一張日期落在那個月的傳票嗎？
⇒ 如果不行，系統應該要擋住它
```

**如果來不及回覆**：我們**本輪先不做這個限制**（目前系統還沒有「關帳」這個動作）。
⇒ 這一題不會擋住開發，而它決定下一輪要不要做關帳鎖定。

---
### 補充：我們已經確認過的
```
· 傳票採分錄式（借方／貸方各一欄），過帳前檢查借貸平衡，不平衡不准過帳
· 傳票過帳後鎖住，要修正只能作廢後重開一張，兩張都留著且看得出取代關係
· 每一次修改都留紀錄（誰、什麼時候、改前是什麼、改後是什麼）
· 傳票的附件不會被系統的更新或還原動到
· **傳票日期可以指定（預設為建檔當天），只有「草稿」狀態能改，改過會留紀錄**
```
