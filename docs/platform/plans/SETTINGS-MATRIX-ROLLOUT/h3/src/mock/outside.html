這 7 項不在「設定中心」裡，散在各業務頁面。使用者裁示（SPEC §15）：先不搬進設定中心，在原頁面改白話並加標示，設定中心左側導覽放「其他位置的設定」連結過來；其中影響金額的 4 項加變更管制（傳票科目、扣繳參數、T100 科目、管銷／公益口徑：要等確認期，或由第二位最高管理者核准才生效，接既有的變更管制與變更紀錄），另 3 項維持立即生效但存檔後發通知（獎金預設、營運目標、報價條款）。每項標出：在哪裡改、現在的問題、新畫面、風險標示。每一頁同樣套用「草稿＋固定儲存列＋離開警告」，改了不會立刻寫入。

兩種生效方式一眼分清：變更管制＝儲存後進「待生效」，滿確認期（預設 7 天）或第二位最高管理者核准才生效（放寬方向才需要第二人，其餘只等待）；立即生效＋通知＝儲存就生效，並通知最高管理者與受影響的人。後端要新增的工作：4 個影響金額的項目接上變更管制與變更紀錄；通知元件另一張票。
