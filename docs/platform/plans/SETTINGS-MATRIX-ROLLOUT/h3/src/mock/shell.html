設定改版 mockup：業務與財務規則（甲份）

分支 feat/settings-matrix-rollout ・ 設計階段，使用者看過才實作。設定中心 20 群組／76 欄、7 個獨立頁、7 個「設定中心以外」的項目。欄位名稱、選項、範圍、預設取自設定登錄表（settings_groups.json）；目前值、來源、人名、日期都是假資料。

示範重點：①搜尋與篩選（「與預設不同」「影響大」…）　②勾選「可批次」的項目 → 套用建議值／套用預設組合／重設為預設 → 確認視窗 → 套用 → 「復原這一批」（版本檢查）　③改單一項目：一般項目直接生效；影響大的項目要填原因、要等 7 天才生效，放寬還要第二位最高管理者核准。
