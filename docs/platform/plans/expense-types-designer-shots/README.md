# 請款類型編輯頁：新舊畫面對照截圖（給使用者預覽）

`new_*`＝新的設計器（`expense-types.html?designer=1`）；`old_*`＝目前預設的表格畫面。例子都是「差旅費用請款單」（travel）。
`light`／`dark`＝淺色／深色主題；`desktop`＝1440×900，`phone`＝390×844。新畫面桌機是視窗截圖，其餘為整頁。

預設仍是舊畫面。要看新畫面：網址加 `?designer=1`，或在舊畫面按「改用新的設計畫面」；新畫面內有「改用舊的表格畫面」。

## 截圖裡看到、不是這次改的
1. 「簽核單據類型」下拉顯示「undefined（未登記）」：四個預設類型的定義檔沒有 `docType`（伺服器視同 `extra_expense`），頁面的下拉不認得缺值。舊畫面同樣。
2. 預設「申請人」欄的說明文字寫著「超級管理員可在定義中把 locked 改成 false…」——是預設定義裡的 `help` 文字，會原樣顯示在新畫面的表單上（含工程用語）；建議改寫成白話。
3. 深色主題下「基本設定」等面板標題與背景對比偏低，是這一頁原本的面板樣式（舊畫面同樣）。
