## 1. 今天寫死了什麼（盤點，2026-10-15）
- **報價單清單**（`frontend/pages/quotations.html`）：九個頁籤（進行中／草稿／待審核／已核准／已送出／已確認／已結案／已取消／未成案；「進行中」＝不含未成案與已結案）、預設頁籤 `all`、四段生命週期色帶、十個欄位（版面引擎只能顯示／隱藏與改標題，不能改順序；報價單號、客戶、狀態、案件進度不可隱藏）、固定 `limit=2000` 一次抓回後**全部在前端**篩選／排序／統計、排序只有報價日期／金額／客戶名稱、預設排序＝伺服器 `id DESC`。
- **案件清單**（`js/case-management-list.js`、`pages/case-management.html`）：頁籤 進行中／已成案／已結案／待精算＋看板、`casePageSize`、deal_tag 對應寫死、四個常用篩選（我的／階段逾期／應收逾期／缺文件）、伺服器端排序白名單（報價日期／客戶／金額，金額排序對看不到金額者無效）、預設 `id DESC`。

- **公司預設**：版面引擎（`layout-pages.json`＋模組 `module.json` 的 lists 順序守門），旗標 `builder_layout.<page>` 預設關。

## 2. 分層規則（解析順序）
`個人偏好 ∩ 公司允許 → 公司版面預設 → 今天的寫死值`
1. **公司版面**（版面引擎，最高管理者發布，沿用預覽／發布／還原與放寬走第二位最高管理者核准）決定：可用欄位集合與標題、頁籤集合與標題、預設頁籤、預設排序、預設頁數。
2. **個人偏好**只能在公司允許的範圍內選：隱藏自己不要的欄位、選自己的預設頁籤／排序／頁數。個人永遠不能顯示公司版面隱藏的欄位、也不能顯示角色遮蔽的欄位。
3. 任何一層讀不到、值不合法、或選到不在允許集合 ⇒ 該項退回下一層（最後是今天的寫死值）；不可整頁壞掉。
4. 個人偏好沿用 `user_list_prefs`（payload 加欄位、向下相容；舊 payload 只有排序）。偏好是純顯示，不進稽核、不影響任何單據資料。
5. 顯示格式（千分位／小數位／日期）一律走切片 B 的 `MotrixFormat`；清單不自己再格式化金額或日期。

## 4. 金額遮蔽不變式（寫死、不開放設定）
1. 看不到報價金額者（`quote_money_visible` 為假）：金額、毛利率欄位**資料**由伺服端遮蔽（CM13），版面與個人偏好都不能改變；欄位可顯示但內容是「—」。
2. 排序：伺服器端對遮蔽者忽略「依金額排序」（順序本身洩漏金額大小）；前端排序（報價單頁現為前端排序）在遮蔽者身上只能拿到遮蔽後的值。任何新增的個人排序欄位若與金額有關，必須同樣在伺服端守住；**禁止**新增允許遮蔽者依金額／毛利排序的路徑。
3. 個人偏好**只能縮小**可見集合，不能擴大；新欄位預設不進任何角色的可見集合直到版面明確發布。
4. 伺服器分頁（`quotes_server_paging`）時，統計（本月件數／金額／平均毛利）仍由伺服端依權限計算，遮蔽者不回金額統計。
5. 匯出、PDF、報表不受清單偏好影響。
