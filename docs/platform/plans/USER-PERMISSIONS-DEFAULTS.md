# 權限調整：15 題預設答案（給使用者看；你只改不同意的）

做法路線已定：**先把財務／出納跟 admin 脫鉤 → 再把權限整理成「職責角色」→ 最後逐項取代 admin 的一般管理權限**。下面 15 題我們先填了預設答案（原則：權限越小越好；建立、核可、匯款不要同一個人；金額和個資預設收緊；案件列表和簽核單本身 admin 還是看得到）。**同意就不用管；不同意的，在「你若不同意」欄寫你要的答案回給我們。**

**已同意**：下表 15 題預設答案你都同意了（第 8 題「產生獎金單」維持現狀）；職責角色化 5 件方向也同意。

**另一條一定遵守的規則**：超級管理者**每個功能都能用**，包含所有財務、出納的頁面、按鈕、API、PDF 和通知，不會因為沒勾「出納」「財務」而被擋——這樣財務或出納沒人時，系統不會卡死。（現在 2 位超級管理者只勾財務、沒勾出納，改完後出納功能仍然都能用，我們會用演練驗。）

## 另有 5 件只是想先跟你確認（職責角色化的方向）
1. 預設職責角色：出納、財務會計、業務、採購、工務、專案管理、系統管理——名稱和內容之後都能在畫面改。
2. 一個人可以綁多個角色（兼任）。
3. 每次改權限要填一句原因，系統會記錄「誰改了誰、前後差異」。
4. 每季出一份「誰有什麼權限、多久沒登入」清單，由超級管理者確認或回收；離職／調職自動回收。
5. 超級管理者（現有 2 位）當緊急帳號：日常不用，使用時通知。
