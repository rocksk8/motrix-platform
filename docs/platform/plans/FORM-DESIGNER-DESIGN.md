# 表單設計器（模組建構器＋請款類型編輯頁共用元件）— 設計文件

狀態：第 1 步（只設計，不改正式程式）。原型：`form-designer-prototype.html`（單檔、無後端，雙擊即可開；右上「用語檢查表」「看資料格式」「看成品」可點）。

## 1. 目標與鐵則

使用者原話重點：真正的表單預覽在**中間**；加欄位與設定在**左右**；現在的欄位表（代碼／型別／預填鎖定／僅出納可改／公式…）與版面勾選看不懂；「固定值」不能按 Enter 連續新增；整個 UIUX 要讓**國中程度**看得懂；公式要變成現成選項；「自動帶入人員／部門」要一眼懂，且**每個功能都要這樣清楚**。

| # | 鐵則 | 怎麼落實 |
|---|---|---|
| R1 | 所見即所得 | 中間就是使用者看到的表單（同一個渲染元件，`看成品` 只是關掉編輯框） |
| R2 | 不出現內部名詞 | 代碼、參照、公式、dataClass、optionsFrom 等一律不上畫面（§4 詞彙對照） |
| R3 | **每個設定三件事缺一不可**：白話標題＋一句「這是做什麼」＋看得見的例子 | 原型 `sw()` 必填 `ex` 參數；§6 檢查表逐項列出；**實作時加守門測試：右側面板任何控制項沒有說明＋例子就紅燈**（見 §8 G-D1） |
| R4 | 只點就能完成 | §7 五個新手任務，e2e 只用 click／fill／Enter |
| R5 | 輸出不變 | 存出去的仍是現行定義 JSON（§5），舊定義讀得進來、新輸出舊程式讀得懂 |
| R6 | 不可逆動作可反悔 | 刪除欄位／區塊 ⇒ 6 秒「復原」提示；全域復原／重做（Ctrl+Z／Ctrl+Y） |

```
├ 左 290px ───────┬ 中（彈性，白紙浮在桌面上）────────────────┬ 右 360px ────────────┤

│ 數字 金額 日期   │  [申請人][部門]（點選＝選取，浮出 ⠿↑↓⧉🗑） │ 一定要填（開關）       │

└─────────────────┴────────────────────────────────────────────┴────────────────────────┘
窄螢幕（≤960px）：三欄改「一次一欄」＋底部三顆切換鈕（加入欄位／表單／設定）；點欄位自動跳到「設定」。
```

互動：
- 加欄位：左邊點一下（加在選取欄位後面，沒選就加在最後一區）或拖到中間任一條藍色插入線；新欄位自動選取、游標落在「欄位名稱」。
- 排序：選取後浮動工具列 ↑↓（Alt+↑／Alt+↓）、拖曳 ⠿；跨區塊拖曳＝換區塊。
- 刪除：工具列 🗑／Delete 鍵／右側紅色按鈕 ⇒ 「已刪除『…』［復原］」。
- 區塊：名稱點一下直接改；↑↓ 換順序；🗑 刪區塊（含其欄位，可復原）；「＋ 新增區塊」。
- 草稿：每次改動 600ms 後自動存，頂列顯示「已自動存草稿 hh:mm」；「發布」才生效（沿用現有草稿／發布流程）。
- 空狀態：沒有欄位 ⇒ 大圖＋「從左邊點一個欄位」；空區塊 ⇒ 虛線框「把左邊的欄位拖到這裡」；沒選欄位 ⇒ 右邊「先點一個欄位」。
- 鍵盤：欄位可 Tab 聚焦，Enter／空白＝選取，Delete＝刪除，Alt+↑↓＝移動，Esc＝取消選取／離開輸入框；選項清單 Enter＝新增下一格、Backspace（空格）＝刪除該格、↑↓＝上下格。
- 視覺：token 沿用站內語意色（`--accent`／`--danger`…，淺色／深色各自定義，元件內無寫死色碼）；觸控目標 ≥44px；`prefers-reduced-motion` 關動畫；焦點環可見。

## 5. 資料相容（輸出仍是同一份定義 JSON）

設計器內部狀態 ＝ 現行定義 JSON 加幾個**底線開頭**暫存欄（`_money`、`_calc`），輸出時一律剔除。對應：

| 畫面動作 | 輸出 |
|---|---|
| 左邊「金額」 | `{type:"number", min:0}`（`_money` 只影響顯示「元」；讀舊檔時 key 為 amount/…不強判，單位後綴不寫入 JSON） |
| 選人員／選部門 | `{type:"ref", target:"users"｜"departments"}` |
| 區塊 | `ui.form.groups:[{title, fields:[key…]}]`；全部放一區＝與「空 groups」等價，輸出一律寫明群組 |
| 在清單中顯示 | `ui.list.columns:[key…]`（順序＝欄位在表單中的順序，不再手動排） |
| 自動帶入 | `default`：申請人本人 `{"$":"requester"}`、今天 `{"$":"today"}`（**現有**）；其餘 ✦ 來源見 §6.3；固定內容＝字面值 |
| 「不能改」 | `locked:true`（請款類型專用屬性，沿用） |
| 只有出納能修改 | `editableBy:"cashier"`（僅 pay_terms／remit_date／pay_date，見 §9） |
| 選項清單 | `options:[…]`（空字串列在存檔時濾掉；全空 ⇒ 發布前檢查擋下） |
| 自動計算 | `formula` 字串（§6.2 對照）；認不得的舊公式原樣保留、顯示「進階公式（只有最高管理者可改）」 |
| 內部代碼 | 新欄位由名稱轉出：中文名稱無法轉拼音 ⇒ 用 `種類_序號`（如 `text_3`）；發布後唯讀 |

不認得的欄位屬性／頂層鍵（例如 `output.template`、`access`、`minSelect`…）**原樣往返不丟**（只編輯畫面上有的屬性）。

## 6. 功能清晰度規則與檢查表（使用者可逐列審字句）

規則 R3：**沒有「白話標題＋一句說明＋範例」的選項，不准出現在畫面上。** 原型右上「用語檢查表」按鈕會把下表以同一份資料即時列出（計算器、自動帶入直接取自畫面實際使用的資料，改字就同步）。

### 6.1 一般設定

| 設定 | 白話標題 | 一句說明 | 例子 |
|---|---|---|---|
| 欄位名稱 | 欄位名稱 | 表單上顯示給使用者看的字 | 「出差地點」 |
| 說明文字 | 說明文字（選填） | 會用小字顯示在欄位下面 | 「請填發票上的金額」 |
| required | 一定要填 | 開起來，使用者沒填就不能送出 | 沒填地點，按送出會跳出提醒 |
| 種類互轉 | 想改成 | 換成相近的種類，已輸入的選項會留著 | 文字 ⇒ 單選選單 |
| options | 選項（使用者可以選哪些） | 一格一個，Enter 新增下一格，可貼多行、拖曳排序、✕ 刪除 | 國內／國外 |
| 明細表欄 | 表格的欄位 | 明細表有哪幾欄 | 類別、品名、數量、單價、小計 |
| locked | 「○○」不能改 | 帶入後使用者看得到但不能改 | 「申請人本人」不能改 |
| editableBy | 只有出納能修改 | 其他人看得到但不能填 | 「付款日」 |
| list.columns | 在清單中顯示 | 開起來，欄位會出現在單據清單 | 清單多一欄「地點」 |
| 內部代碼 | 系統內部代碼（進階，僅最高管理者） | 自動產生，發布後不能改；改名稱不會動它 | place |
| 區塊 | 區塊名稱／＋ 新增區塊 | 把欄位分成幾段 | 基本資料、出差資訊 |
| 看成品 | 看成品 | 隱藏編輯用的框線，看實際樣子 | — |
| 復原／重做 | 復原、重做 | 做錯可回上一步 | Ctrl+Z |
| 草稿 | 已自動存草稿 | 改了自動存；按「發布」才給使用者用 | 已自動存草稿 14:32 |

### 6.2 自動計算：現成計算器（不打公式）

每個計算器：一句說明＋範例；選好後欄位預覽直接顯示**活範例數字**。對應既有公式字串（`helpers.formula` 函式）：

| 計算器 | 說明 | 範例 | 輸出 `formula` |
|---|---|---|---|
| 加總明細 | 把明細表每一列的某個金額加起來 | 1,000＋2,000＋3,000＝6,000 | `total(lines, "amount")` |
| 加總欄位 | 把勾選的幾個數字欄位加起來 | 機票 1,000＋住宿 2,000＝3,000 | `a + b + c` |
| 稅額計算 | 輸入未稅 ⇒ 算稅額或含稅；輸入含稅 ⇒ 拆稅。稅率 5%／免稅／自己填 | 未稅 10,000、5% ⇒ 稅額 500、含稅 10,500 | `round_half_up(a * 0.05)`／`round_half_up(a * 1.05)`／`round_half_up(a - a / 1.05)` |
| 數量 × 單價 | 兩欄相乘 | 3 × 500＝1,500 | `a * b` |
| 百分比 | 某金額的幾 % | 10,000 的 30%（訂金）＝3,000 | `round_half_up(a * 30 / 100)` |
| 相減 | A 減 B | 10,000 − 4,000＝6,000 | `a - b` |
| 日期相差幾天 | 兩個日期相差幾天 | 5/1～5/4＝3 天 | `days_between(a, b)` ✦ |

- 讀舊定義：以字串樣式反解成計算器（`parseCalc`）；認不得 ⇒ 顯示「進階公式」唯讀，只有最高管理者可換成現成計算器。
- ✦ 需確認／新增：`days_between` 若 `helpers/formula.py` 尚無，需加（純函式＋測試）。稅額輸出用 `round_half_up`（現有）。明細表**列內**的公式欄（如 `round_half_up(qty * unitCost)`）本步不開放自由編輯，沿用「小計」現成欄（qty＋unitCost 同時存在時伺服器本來就會算）。

### 6.3 自動帶入（選單；每個選項附說明與範例；沒選＝不帶入）

| 適用欄位 | 選項 | 說明 | 使用者看到 | JSON | 後端現況 |
|---|---|---|---|---|---|
| 選人員 | 申請人本人 | 填表的人是誰就帶誰 | 王小明 | `{"$":"requester"}` | 現有 |
| 選人員 | 目前登入的人 | 現在操作的人（代理填表時可能不同於申請人） | 李助理 | `{"$":"currentUser"}` | ✦新增 |
| 選人員 | 申請人的主管 | 人事資料的直屬主管 | 陳經理 | `{"$":"requesterManager"}` | ✦新增 |
| 選部門 | 申請人所屬部門 | 人事資料的部門 | 業務部 | `{"$":"requesterDept"}` | ✦新增 |
| 日期 | 今天日期 | 打開表單那天 | 2026/10/01 | `{"$":"today"}` | 現有 |
| 日期 | 固定某一天 | 你指定的日期 | 2026/12/31 | 字面值 | 現有 |
| 文字 | 公司名稱 | 系統設定的公司名 | ○○機械股份有限公司 | `{"$":"company"}` | ✦新增 |
| 文字 | 這個案件的客戶／專案 | 從案件帶入（只有掛在案件底下的表單才有） | 台灣精密／新廠自動化 | `{"$":"caseCustomer"}`／`caseProject` | ✦新增（依掛載點 context） |
| 文字／選單／圓點／選人員／選部門／日期 | 我上一次填過的內容 | 這個人上次填同一格的內容 | 台北出差 | `{"$":"lastUsed"}` | ✦新增（伺服器查本人最近一筆） |
| 文字／長文字／數字／金額／勾選 | 固定的內容（我自己打） | 每次都先填好這段 | 依輸入 | 字面值 | 現有 |
| 單選選單／圓點 | 先選好某一個選項 | 預先選一項 | 國內 | 字面值 | 現有 |

規則：每個選項下方「說明＋使用者會看到」框隨選擇即時更新。選了自動帶入才能開「○○不能改」開關，標題帶出實際名稱（如「『申請人本人』不能改」）。✦ 在選單中以標記註明；實作時由後端 `PREFILL_SOURCES` 註冊表單一來源提供（前端選單、驗證、說明文字皆讀該表，避免兩份）。

## 7. 五個新手任務（只靠點擊；原型右下「試試看」會自動打勾；之後轉 e2e）

1. **加一個「備註」長文字框**：左邊點「長文字」→ 右邊欄位名稱改「備註」。驗：定義含 `type:"textarea", label:"備註"`，且出現在最後一個區塊。
2. **把「地點」改成選單，選項「國內」「國外」**：點「地點」→「想改成」選單選「單選選單」→ 選項第一格打「國內」Enter 打「國外」（並刪掉預設多餘格）。驗：`type:"select", options:["國內","國外"]`。
3. **把「金額」搬到最下面的區塊**：拖曳（或 ↓ 鍵）。驗：`ui.form.groups` 最後一組含 amount。
4. **讓「總額」自動加總費用明細的小計**：點「總額」→ 計算器選「加總明細」→ 選「費用明細 ➜ 每一列的小計」。驗：`formula === 'total(lines, "amount")'`；預覽顯示範例 6,000。
5. **把「備註」從清單中隱藏**：點「備註」→ 關閉「在清單中顯示」。驗：`ui.list.columns` 不含備註的 key。

另加三個建議 e2e（驗清晰度）：貼上多行選項自動拆格；刪除後按「復原」還原；窄螢幕三欄切換。

## 8. 守門與測試（實作期）

- G-D1（清晰度）：右側面板每個 `.row`／`.switch`／計算器卡片必須同時含「標題」與「說明」，且含「例」（`small.ex`／`.why` 內含「例」）；沒有就紅燈。附反向控制（拿掉 ex ⇒ 抓得到）。
- G-D2（相容）：每個既有定義（`expense_type_defs/*.json`、現有自訂模組 fixtures）→ 載入設計器 → 不動 → 輸出 ＝ 原 JSON（含不認得的鍵）。
- G-D3（詞彙）：右側／左側／中間編輯框畫面文字不得出現禁用詞表（代碼、參照、公式、dataClass、options、formula、locked、editableBy…）；進階折疊區除外。
- 每個計算器 `build ⇄ parse` 往返測試；不認得的公式不被改寫。
- 元件共用：`static/form-designer.js`（單一來源），module-builder 與 expense-types 皆以「適配層」餵入／取出各自的定義（請款類型適配：保留 `lines` 唯一、保留字欄位固定種類、帳號類字眼禁用…見 §9）。

## 9. 請款類型編輯頁（a3 整合）要保留的能力（a3 盤點，逐項對應）

來源：`expense-types.js`＋`expense_types.py validate_expense_type`。設計器核心不內建這些；以**適配層／外框**提供。

| a3 項目 | 處理 |
|---|---|
| A 類型標頭：名稱、編號前綴、payable、enabled、docType、新類型代碼 | 在設計器**上方的「類型設定」摺疊卡**（外框，非設計器本體）；白話：「請款單名稱」「單號開頭字母」「核准後要不要交給出納付款」「啟用中（關掉＝新單不再出現）」「簽核表單類別」；新類型代碼自動產生、顯示為進階。**同樣遵守 R3**（標題＋說明＋例） |
| B 欄位基本屬性、型別專屬屬性（placeholder/maxLength/min/max/unique/withTime/allowOther/minSelect/maxSelect/multiple/accept/maxFiles） | 右側面板依欄位種類顯示對應項目，各自白話＋例（例：`maxLength`⇒「最多幾個字」；`accept`⇒「接受哪些檔案」 ）；本步原型只示範常用屬性，完整清單在實作切片逐一補入檢查表 |
| B 專屬 `locked`、`editableBy` | 「不能改」「只有出納能修改」；後者**只在 pay_terms／remit_date／pay_date 開放**，其他欄位開關停用並說明「這個設定只有付款相關欄位能用」 |
| B 預設值 `$requester`／`$today`／固定值 | §6.3（現有三種完整保留） |
| B 保留字欄位固定種類（applicant/dept/cost_dept/req_date/pay_date/urgency/pay_terms/remit_date） | 左邊「請款常用欄位」分組（只在請款類型頁出現）：申請人、部門、成本部門、申請日期、付款日、緊急程度、付款條件、匯款日；加入後**不可改種類**（「想改成」隱藏），urgency 選項固定「一般／急件／特急」（選項清單唯讀、說明原因） |
| B 禁用字眼（銀行／帳號…） | 即時檢查欄位名稱，輸入時就提醒；不等伺服器 validate |
| C 明細表 `lines`：唯一一個、minRows/maxRows(≤200)/addLabel、欄位必備 category/summary/amount、qty＋unitCost 成對、`optionsFrom:expense_categories`、未知列鍵保留 | 左邊「明細表」按鈕在請款頁只能加一次（已有則停用並說明）；右側「明細表設定」：最少幾列、最多幾列、按鈕文字；欄位清單以項目清單呈現，必備欄（費用類別／品名／金額）不可刪並標「必要」；數量與單價自動成對加入／移除；其餘欄（發票號碼等）一鍵加入或自訂 |
| D 版面：groups、list.columns、全放一組 | 區塊＋「在清單中顯示」；「全放一組」＝刪到只剩一個區塊 |
| E `output.template` 不編輯 | 原樣往返 |
| F 流程：伺服器驗證、預覽、存草稿、捨棄草稿、與已發布差異、版本列表、還原為新版本、發布附備註 | 外框保留：頂列「發布」開對話框（備註）；「檢查」＝呼叫 validate，問題以清單列出且**可點選跳到該欄位**；預覽被中間畫面取代（保留「看成品」）；「放棄草稿」「與已發布版的差異」「版本」放頂列「更多」選單 |
| G testids | **全部沿用現有名稱的機會有限**：版面重做後（et-fields／et-field-row／et-f-* 等表格式元素）不再存在。作法：適配層在新元素上補相同 `data-testid`（et-save／et-publish／et-validate／et-problems／et-note／et-versions／et-restore-{n}／et-name／et-prefix／et-doctype／et-payable／et-enabled／et-new／et-back／et-list…保留）；欄位級 testid（et-f-*）改為新定位器，a3 同步改測試。 |

## 10. 模組建構器（B）要保留的能力

沿用 `module-builder-*.js` 目前功能：分類／選單位置（`menu`）、掛載點（`mount`：point／label／contextField）、流程（workflow）、輸出、權限（`access.visibleTo/editableTo`）。這些屬於**表單以外的外框**，設計器只取代「欄位清單＋版面」兩段；其餘各段在實作切片依同一 R3 規則改白話（本步不做）。

## 11. 實作切片建議（待使用者看過原型後）

1. `static/form-designer.js`（核心：狀態、動作、復原堆疊、中間渲染）＋`css/form-designer.css`（token）＋單元測試（build/parse 往返、G-D2）。
2. 右側面板（選項項目清單、自動帶入選單、計算器）＋G-D1／G-D3 守門。
3. 模組建構器接入＋五個新手任務 e2e。
4. 請款類型頁接入（a3）＋適配層＋既有 e2e 改定位器。
5. 後端：`PREFILL_SOURCES` 註冊表（✦ 來源）＋ `days_between`。
