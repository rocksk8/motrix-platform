## 題 1：網路規劃書「已交付」之後，還能不能修改？

現況：畫面上，「已交付」的規劃書是唯讀、不能改；但系統後端沒有擋，用其他方式送出修改仍然會成功。兩邊不一致。

1. **後端也擋，已交付就不能改（建議）**——和畫面一致；要改須先把狀態改回「已確認」。影響：需要修訂已交付的規劃書時，多一個「改回狀態」的步驟，並留下紀錄。
2. 兩邊都放寬，已交付仍可修改——影響：交付後內容可能被改動而沒有明顯痕跡。
3. 做成設定，由管理者選「已交付可否修改」，預設為不可——影響：多一個要管理的設定；放寬時需要第二位最高管理者核准。

## 題 2：每日工作事項的「主管」，能不能匯出歷史紀錄（CSV）？

現況：主管可以在畫面上看到所負責成員的歷史，但不能匯出；只有被指派者本人和最高管理者能匯出。

1. **主管可匯出自己負責成員的歷史（建議）**——和「可以看」一致。影響：主管可取得成員的工作紀錄檔案；匯出會留下稽核紀錄。
2. 維持現狀，主管只能看、不能匯出——影響：主管需要資料時得請最高管理者匯出。
3. 做成設定，由管理者選「主管可否匯出」，預設為不可——影響：多一個設定；放寬時需要雙人核准。

## 題 3：每日工作事項的「完成回報」，最高管理者或主管能不能代替被指派者回報？

現況：只有被指派者本人能回報完成，連最高管理者也不能代報。

1. **維持只有被指派者本人（建議）**——回報代表本人確認，紀錄最可信。影響：人員請假或離職時，任務要先改派才能回報。
2. 允許最高管理者代報，並在紀錄註明「由某某代報」——影響：方便處理離職與請假，但完成紀錄不再全是本人確認。
3. 允許任務的負責主管代報，並註明代報人——影響：同上，範圍更廣。
4. 做成設定，由管理者選誰可以代報，預設為不可——影響：多一個設定；放寬時需要雙人核准。

> 若使用者不想逐題裁示：三題各取第 1 個選項即為建議組合（後端跟畫面一致、主管可匯出、維持本人回報）。
