> 2026-11-13，hichan-1。**凍結的是「旗標全關＝今天的行為」**，程式基底 T81（`adc6bd58d`）。後續各批驗收時「前後對照表」引用本檔，**無一項增加**（提案 v3 §2.5 第 10 條）。
> 標註：**【讀碼】**＝逐步對過程式／畫面截圖；**【推算】**＝依畫面結構推得，未用瀏覽器逐步點過（P2 起每批要補一支 e2e 計步，見末段）。

## 計數規則

1. 只算**使用者的點擊／點選**（連結、按鈕、頁籤、下拉選項、勾選）；不算捲動、不算打字、不算瀏覽器上一頁。
2. 以「已登入、停在案件管理列表、案件已存在」為起點；側欄項目算 1 次點擊（群組預設展開）。
3. 日期欄位有預設值（今天）者，不改日期＝不計。
4. 「離開目前頁面再回來」不另計，但在備註寫出（那是隱性成本：情境會掉）。

## 補量方式（P2 起）

每批在 e2e 中以固定函式計步：

```js
// 在 page 注入，計「可信任的」使用者點擊（isTrusted），排除程式觸發
window.__clicks = 0
document.addEventListener('click', e => { if (e.isTrusted) window.__clicks++ }, true)
```

每個 S 任務一支測試，跑完把 `window.__clicks` 與本表比對；**旗標開的結果不得大於本表**。S4／S5 的「未計儲存」「≥」在 P2 補成確切數字並回寫本檔（不回改已凍結的 S1～S3）。
