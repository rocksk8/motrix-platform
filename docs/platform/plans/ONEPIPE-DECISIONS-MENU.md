## 先講目前進度（不需要老闆決定的部分已經做完）

下面五批**不動權限、不動簽核、不改資料結構**，各有自己的開關（預設關，關掉＝跟今天一模一樣），已經做完、審過，等上線：

- 案件裡直接開請購單／採購單、死連結修好、保固頁案號可點
- 工程師寫工作日誌可以選案件
- 序號先出貨、後登載設備不再報「序號衝突」
- 案件新增「物料流程」時間軸畫面（只看、不能改、不顯示金額）
- 已結案案件的保固到期也會通知（開關預設關）

**以下 11 題是剩下的批次要先決定才能開工的事。**

## 哪些選擇會被「第二位最高管理者核准」管（先看這個）

| 類型 | 規則 |
|---|---|
| 看金額、看敏感資料等「高風險動作」放寬 | 〔現行規則〕要原因、等確認期，**第二位最高管理者核准** |
| 調整單據流程（誰簽核、要不要簽核）放寬 | 〔現行規則〕走最高管理者核准流程與確認期 |
| 入庫、建立請購單、新增每日事項 | 今天**沒有**這道核准（程式裡寫死「限管理員」等），改了就立即生效；要不要新增這道規定是〔新規定〕，可採用也可不採用 |
| 只有一位最高管理者的公司 | 沒有第二位可核准，改為「寫明原因＋等待確認期＋警示通知」 |

## 第一組：誰能做什麼（權限類，共 3 題）　建議先問這組

### D3　被授權「採購」的人，可以做什麼？　✅ 已裁示 2026-11-13（使用者）：**A**
- **背景**：「採購」「庫存」不是帳號類別，而是勾選的模組權限。新進採購現在看得到「採購管理」，但只能看、不能做事；供應商名單對他是空的；請購單入口也被擋住。
- **A　可建請購單、可看供應商「唯讀」名單；材料申請仍需有看金額的權限**　→ 影響：新進採購第一天就能開始做事，金額不外露；需先確認供應商名單的銀行帳號欄位對採購是遮住的（過去出過外露的缺口）。
- **B　A 再加「可建材料申請」**　→ 影響：材料申請單有單價與金額欄，採購沒有看金額權限時要二選一：遮住（要改表單，中等工作量）或顯示（等於給他看金額，是高風險動作）。
- **C　維持現況（只能看）**　→ 影響：不需要任何變更，但新進採購仍然只能看。
- **建議：A**。最小的一步就讓採購能動手，又不碰金額。
- **規則**：請購入口與看供應商名單是〔新規定才會被管〕，今天立即生效；若做到「看金額／看敏感資料」才是〔現行規則〕，需第二位核准。
- **之後能不能改**：收緊隨時、立即生效；再放寬又要走一次核准。
- **卡住哪一批**：「採購第一道牆」；「供應商主檔」也要這題決定供應商資料給誰看。

### D9　誰能做「入庫」（新增進貨、修改進貨）？　✅ 已裁示 2026-11-13（使用者）：**A＋採用新規定**
- **背景**：現在只有管理員能入庫，採購與現場工程師做不了。這題決定「一站式到貨」（到貨一次登完，案件與倉庫同時更新）能不能真的一站完成。
- **A　開放給「擁有採購或庫存模組權限」的人**　→ 影響：到貨可以一次登完；但能修改進貨資料（含成本）的人變多。
- **B　維持只有管理員**　→ 影響：非管理員到貨只能完成案件那一半，每批貨都要管理員補一步入庫；畫面會有一張「案件已到貨、庫存還沒有」的對帳清單給管理員補登。
- **建議：A，並採用新規定**（入庫列為權限矩陣裡的一個動作，授予要寫原因、等確認期、之後放寬要第二位核准）。理由：一站式到貨的重點就是不必再轉手給管理員；新規定把擴大權限的風險管起來。若老闆不想增加管控，也可選 A 不採新規定（立即生效），或選 B。
- **規則**：入庫今天不屬於高風險動作、不需第二位核准；「採用新規定」是〔新規定〕，可不採用。
- **之後能不能改**：收緊隨時；放寬依上面規則。
- **卡住哪一批**：「入庫底層」與「一站式到貨畫面」。

### D5　每日工作事項要不要開放現場人員新增？　✅ 已裁示 2026-11-13（使用者）：**A**
- **背景**：現在只有最高管理者能新增，而且新增時帶不到案件資訊。
- **A　開放現場人員新增「跟自己有關、掛在案件上」的事項；修改與刪除仍只有最高管理者**　→ 影響：工程師可自己建事項，不必請最高管理者代建，範圍已限縮。
- **B　維持現況**　→ 影響：工程師仍要請最高管理者代建。
- **建議：A**。範圍已限縮、修改刪除仍管住，不需要再加第二位核准。
- **規則**：新增每日事項今天不屬於高風險動作，改了立即生效；要不要加第二位核准是〔新規定〕，我們建議不必。
- **之後能不能改**：隨時。
- **卡住哪一批**：「紀錄整併」（把日誌、每日事項、出勤、完工單串進案件）。

## 第二組：這一輪做多大（範圍類，共 3 題）

### D2＋D8（連動，請一起答）　要不要做「領料單」？線材、接頭這類沒有序號的耗材怎麼辦？
- **背景**：系統目前沒有領料單；庫存假設每一件都有序號；沒有序號的耗材（線材、接頭）現在**沒有任何地方可以登記**。這兩個問題互相牽動，只有下面兩種搭配成立（其他搭配做不通）。
- **A　先不做領料單；耗材以材料申請的數量為準，到貨就視為現場領用，不進庫存**　→ 影響：工作量最小，但看不到耗材餘量；之後要加領料單是另開一批，可以做。
- **B　現在就做領料單（領用、扣庫存、記領用人），耗材進庫存、以數量計、領料才扣**　→ 影響：要新增「數量型庫存」與一整張領料單，整體範圍約變成兩倍。
- **建議：A**。先把到貨、出貨、設備這條線走順，領料單等有實際需求再加。
- **規則**：只決定範圍，不涉及權限規則。
- **之後能不能改**：A 之後要加領料單＝另開一批新增工作，可以。
- **卡住哪一批**：「一站式到貨畫面」的範圍。

### D1　叫來的料，一定都要入庫嗎？
- **背景**：只針對有序號的品項。有些案子貨直接送客戶現場，不經倉庫。
- **A　到貨時二選一：入庫，或直送客戶現場（直送的仍可登載序號與設備）**　→ 影響：時間軸上直送的那格顯示「略過」，直送的序號沒有庫存側紀錄（設備登載照常）。
- **B　一律入庫**　→ 影響：每筆到貨都要走倉庫流程，沒有倉庫的現場直送案要想辦法變通。
- **建議：A**。符合現場實況，而且 A、B 之間之後隨時可以換。
- **規則**：只決定範圍，不涉及權限規則。
- **之後能不能改**：A→B、B→A 都容易。
- **卡住哪一批**：「入庫底層」與「一站式到貨畫面」（影響入庫那格怎麼顯示）。

### D10　退貨、送修、換貨要不要一起做？
- **背景**：序號現在只有「在庫／已安裝／已出貨／作廢」四種狀態，沒有退貨。
- **A　本輪不做，另案評估（換機、退貨仍靠人工與留言）**　→ 影響：現場常見的退換貨仍沒有系統支援。
- **B　納入（新增退貨狀態，並連動案件與保固）**　→ 影響：範圍約再多一批，而且會動序號狀態與保固。
- **建議：A**。先把主線做完，退換貨另案設計比較不會彼此拖累。
- **規則**：只決定範圍，不涉及權限規則。
- **之後能不能改**：A→B＝新增一批，可以。
- **卡住哪一批**：「出貨／設備／保固對齊」的範圍。

## 第三組：流程與細節（共 4 題）

### D6　「請購→採購→材料申請」目前要簽兩次，怎麼處理？
- **背景**：現在新的材料申請**必須**連到已核准的採購單才能送審，所以一筆採購要簽兩次（採購單一次、材料申請一次）。我們判斷這是「太零散」感覺的來源之一（這是我們的推論，不是使用者說的）。**這題不擋任何批次**，其他批次不必等它。
- **A　維持兩次核准（現況）**　→ 影響：沒有開發成本；兩次簽核照舊。
- **B　材料申請連到「已核准採購單的明細」就不再簽第二次（以採購單核准為準，到貨仍要確認）**　→ 影響：這是新設計，工作量中等，還要先定「材料申請與採購單內容不一致時怎麼辦」；已在簽核中的不追溯，只有之後新送審的適用；**屬於放寬簽核**。
- **C　回到只簽材料申請、採購單不再是前提**　→ 影響：採購單與材料申請脫鉤，兩份資料靠人對照；與「連成一條」的方向相反。
- **建議：B**；若老闆不想放寬任何簽核，選 A。不建議 C。
- **規則**：B、C 屬放寬簽核＝〔現行規則〕，須經最高管理者核准流程與確認期（只有一位最高管理者的公司：降級為原因＋確認期＋警示）。C 目前只是程式裡的常數，改了發版就生效、沒有規則會攔，所以若選 C 要先把它變成設定中心裡受管的設定。
- **之後能不能改**：B／C 上線後要回到 A＝收緊，立即生效。
- **卡住哪一批**：不擋任何批次；若選 B 或 C，會多一批「簽核流程調整」，排在最後。

### D7　分批到貨、少交貨，要怎麼記？
- **背景**：現在到貨是「每張材料申請一個到貨日」，沒有「到了幾件」；到貨後要改數量得退回草稿重簽，所以分批到貨只能拆單。
- **A　材料申請新增「已到數量」欄位，可分批累計（時間軸顯示「到貨 4／12」）**　→ 影響：要先定累計規則與超收怎麼辦；欄位一旦有資料就不好完全回退；不影響簽核（到貨欄位本來就不算要重簽的內容）。
- **B　維持拆單重簽（現況）**　→ 影響：分批到貨永遠只能拆單，時間軸只能顯示「這張到了／沒到」。
- **附帶**：要不要新增「預計到貨日」？現在沒有這個欄位，系統也刻意不追供應商前置時間。**建議先不加。**
- **建議：A**。現場分批到貨很常見，沒有數量就看不出進度。
- **規則**：不涉及權限規則。
- **之後能不能改**：選 B 之後想改 A 隨時可以（加欄位）；選 A 之後想拿掉，已寫的數量會變成歷史資料，不好完全回退。
- **卡住哪一批**：「一站式到貨畫面」。

### D4　設備保固的起算日，預設取哪一天？
- **A　預設出貨日；沒有出貨單（直送）時依序退到到貨日、完工日。只是「預填」，存檔前由人確認，不會自動寫入；設定中可改成以完工日為預設**　→ 影響：多數設備不用手填起算日，又不會靜默改掉保固。
- **B　預設完工／驗收日**　→ 影響：貼近「驗收後才算」的合約，但完工日還沒填之前沒有預設值。
- **C　維持空白（現況）**　→ 影響：沒填起算日的設備永遠不會被保固到期提醒。
- **建議：A**。
- **規則**：不涉及權限規則；保固起算常是合約條款，預設值屬商業判斷，請老闆確認自家合約怎麼寫。
- **之後能不能改**：預設值隨時可改，已存的設備不會被追溯修改。
- **卡住哪一批**：「出貨／設備／保固對齊」。

### D11　輪到下一個人時，要不要通知他？
- **背景**：成案、採購單核准、到貨確認，現在都不會通知下一步的人，採購要自己每天打開畫面看。
- **A　要：輪到某人時站內通知他（只通知「輪到你」的人，避免轟炸）**　→ 影響：多一批小工；走 LINE 的部分由 LINE 負責的視窗接。
- **B　不要：靠時間軸上的「卡在誰手上」自己看**　→ 影響：採購仍要每天打開畫面。
- **建議：A**。
- **規則**：不涉及權限規則。
- **之後能不能改**：隨時。
- **卡住哪一批**：「通知下一個人」。
