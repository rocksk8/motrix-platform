LINE 通知：要發哪些、發給誰

設計 mockup（示意資料）：事件名稱與群組取自真實的事件目錄（70 項，10 個群組，不含獎金／薪資／勞報單）；開關、收件對象、發送則數、人員都是假的，所有操作只在這個頁面裡生效、重新整理就還原。

新開啟的事件，預設發給： LINE 只給特定人：從「關」切到「開」時，若事件目前是「照原本收件人」，會依這裡自動改成指定對象；之後仍可逐項調整。
圖例： 指定收件（這個角色會收） 篩選原本收件人（這個角色的人才收） 不收 點格子即可切換；勾左邊方塊選多個事件，再用下方的批次列一次套用。

每一則 LINE 訊息「每位收件人算一則」，免費方案每月 200 則；用量到 90% 時，非「重要」事件會自動暫停。「近 30 天」是已開啟事件實際推出的則數。

這是現行畫面的重現（只列前面幾項）。實際有 70 項，每一項都長這樣：各自一個勾選、6 個角色勾選、再各自展開「設定誰要發」；沒有搜尋、篩選、批次，也看不到用量。
