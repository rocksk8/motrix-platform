- **「裁示」欄是逐字引用**，出處是下列三份文件（皆在 `origin/host/quick-memory-pointer`，除另註）：

  - `HANDOFF`＝`docs/platform/plans/HANDOFF-HOST-20261003.md`（主持 2026-10-03 夜交接；§3 為主持**彙整**的已裁示清單，不是使用者逐字）。

- 本檔不新增任何裁示；原話找不到的（例如主持轉述的稅口徑 B）標明「經主持轉述」，待主持補入原文。
