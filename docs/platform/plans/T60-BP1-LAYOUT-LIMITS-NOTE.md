## 案件清單（卡片）
1. **改名只對「業務」有可見效果**：卡片上多數項目沒有文字標籤，`relabel` 其他項目不會改變畫面；只有「業務：」前綴讀版面標籤。
2. **金額／階段進度／日期共用底部一列**：整列的位置由三者中最前面的可見項目決定，列內順序依版面。
3. **編輯按鈕**只在旗標開啟時插在「多選」開關旁；看板與矩陣檢視不可自訂。

## 案件資訊表單（合約資訊、專案期間）
4. **每個表單只登記第一個區塊**：編輯器仍提供「新增區塊」「把欄位移到別的區塊」，但這一頁不會因此改變畫面。
5. **合約資訊格線的欄寬依 DOM 位置的 CSS**（前兩格較寬）：欄位重排時欄寬跟著欄位走，不是跟著位置。
6. 不在範圍：人員角色（涉及負責人指派）、合約備註、金額與款項欄位；現場聯絡人、聯絡電話、開始日期為核心欄位（個資告知相關，不能隱藏）。
