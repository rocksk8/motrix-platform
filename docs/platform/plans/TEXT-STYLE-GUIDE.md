適用：畫面文字、通知文字（LINE／Email／站內）、說明文件。依據 PM 定稿（`D:\Claude-pm\t85-text-train.md`）；本檔把準則落成可逐條查核的規則與用語表。盤點資料見 `TEXT-INVENTORY/`（`strings.csv` 為全量字串、`summary.md` 為各區塊計數、`scan_text.py` 為靜態掃描器）。

## 1. 語氣

1. 專業、正式、簡潔、中性。面向使用者的第二人稱一律「您」，不用「你」。
2. 不用口語與網路用語：搞定、喔、啦、囉、超（快／好）、爆（量）、GG、哇、耶、欸、讚、酷、爽、掛了、別擔心、放心、不用怕。
3. 不用表情符號（pictographic emoji）與驚嘆號；不用「～」「XD」。
4. 不用不確定語氣的口語副詞當說明：好像、應該會、大概、蠻、弄、搞。需要表達條件時用「若…，則…」。
5. 不用「點一下」這類口語動作 → 「按一下」或「選取」。「看一下」→「查看」；「看有沒有…」→「確認是否…」；「有沒有／是不是／會不會」→「是否」。
6. 不說「幫您／幫你」→「為您」或直述。「大家」→「所有使用者」。

> 例外：問候語「輕鬆幽默」風格是使用者可選功能，**保留**（只修錯字與標點，不改風格、不刪表情符號）。預設「溫和正式」文字一併檢查，仍須符合本節。

## 2. 句式

| 元素 | 規則 | 例 |
|---|---|---|
| 按鈕、選單 | 動詞開頭、不加標點、不加「請」 | 儲存、送出審核、匯出、新增客戶 |
| 提示、說明 | 完整句，句末全形句號「。」；短標籤（欄位名、頁籤名）不加句號 | 此欄位由管理者維護，修改後立即生效。 |
| 錯誤訊息 | 「發生什麼＋怎麼處理」 | 解鎖密碼不正確，請重新輸入。 |
| 確認對話 | 說明後果，不用「確定要…嗎？！」 | 刪除後無法復原，是否繼續？ |
| 空狀態 | 敘述事實＋下一步 | 目前沒有資料。請按「新增」建立第一筆。 |
| 進行中 | 「載入中…」「處理中…」（單一個省略號字元「…」，不用 `...`） | |
| 成功 | 「已儲存。」「已送出審核。」（過去式，不用「成功囉」） | |
| 必填 | 「必填」；提示用「請填寫○○。」「請選擇○○。」（統一用「填寫」，不用「填」「輸入」混用於同一類欄位） | |

## 3. 標點與排版

1. 中文語境一律全形：，。：；「」『』（）？、。引號用「」，不用 `""`。
2. 數字與英文字母用半形。
3. **中文與半形英文／數字之間加一個半形空格**——此為現行慣例（全系統 5,037 處有空格、446 處緊貼，約 92% 對 8%），本車統一為「有空格」，把離群的緊貼寫法補齊（掃描器代號 C7）。
   - 全形標點與英數之間不加空格：`（Email）`、`第 3 列，` 不是 `第 3 列 ，`。
   - 不加空格的例外：單位與符號貼數字（`50%`、`NT$` 後直接接數字、`5 分鐘` 仍加空格）、版本號、檔名、代碼、URL。
   - 品牌／專名內部不動：`MOTRIX PLATFORM`、`LINE`、`PDF`。
4. 省略號用「…」（單一字元），不用 `...`（C8）。
5. 版面符號 ✓ ✗ ⚠ ● ○ ★ → 等屬版面元素（狀態標示、箭頭），**不視為表情符號，不動**（C9 只計數）；彩色 emoji（✅ ❌ 🔴 ✨ 等）改為文字或既有版面符號，問候語庫除外。
6. 破折號用「──」或「—」現行用法不動；不在本車統一。

## 4. 名稱

- 系統一律稱 **MOTRIX PLATFORM**，不得出現 ERP（頁面 `<title>` 的「— MOTRIX ERP」改為「— MOTRIX PLATFORM」；通知內的「MOTRIX ERP 備份警示」同改）。
- 單據：報價單、估價單、估價單號、請款單、勞報單、傳票、完工單、出貨單、請購單、採購單等維持現行名稱，不改。
- 外來專名大小寫：LINE（不寫 Line）、Email（不寫 email／E-mail，句中泛指時用「電子郵件」亦可，見下表）、PDF（不寫 pdf）。

### 5.2 依語境區分（兩者都保留，但畫清界線）

| 詞 | 用法 |
|---|---|
| 登入／登錄 | **登入＝進入系統（帳號登入／登出）；登錄＝把資料記錄登載到系統（登錄付款、登錄發票、設備登錄、已登錄／未登錄）。** 現況（登入 394、登錄 123）兩者已依此分用，不要互換。 |
| 管理者／管理員／最高管理者 | 角色顯示名依 `perm_text.py`／角色表：**最高管理者**（`superadmin`）、**管理員**（`admin`）、業務、工程師、財務、檢視者。泛指「具管理身分者」用「管理者」。「只有管理員可以…」須確認原意是 admin 單一角色還是兩者皆可，**拿不準就維持原字**。「系統管理員」在安裝／維運指令說明（以系統管理員執行 PowerShell）維持，面向使用者的句子改「管理者」。 |
| 儲存／存檔 | 動作用「儲存」（按鈕、提示）；名詞「存檔」只用於「已存檔的報價單」這類既有概念，不新增。「保存」僅用於「保存期間／永久保存」（保存年限）意，不作「儲存」的同義詞。 |
| 刪除／移除／清除／作廢 | **刪除**＝資料不再存在（進刪除暫存區）；**移除**＝從清單／群組／關聯中拿掉但資料仍在；**清除**＝清空欄位或篩選條件；**作廢**＝單據留存但失效。不得互換。 |
| 新增／建立 | 新增＝按鈕與清單加一筆；建立＝系統自動產生或「建立帳號／連結」這類結果。 |
| 修改／變更／更新／編輯 | 編輯＝進入編輯狀態（按鈕）；修改＝內容被改；變更＝簽核異動單的正式用語；更新＝系統版本或重新抓取。 |
| 檢視／查看 | 檢視＝唯讀開啟（「檢視者」角色相關）；查看＝一般看詳情。 |
| 核准／批准／同意／簽核／審核 | 簽核＝流程總稱；核准／駁回／退回＝簽核人的動作；審核＝審查中狀態；「批准」只在既有「批准異動」「批准刪除」維持。 |
| 供應商／廠商／協力廠商 | 供應商＝採購對象；廠商＝泛稱；協力廠商＝外包施工單位。不互換。 |
| 案件／專案 | 案件＝案件管理模組；專案＝報價單上的「專案名稱」「專案經理」。不互換。 |
| 電子郵件／信件／Email／信箱 | 欄位名用「Email」；說明句用「電子郵件」；收件處用「信箱」；「信件」只用在「通知信件」這類內容。 |
| 確定／確認 | 確定＝對話框的肯定按鈕；確認＝動作（「請確認…」「確認收款」）。 |
| 重新整理／重新載入 | 頁面層級「重新整理」；資料層級「重新載入」。 |
