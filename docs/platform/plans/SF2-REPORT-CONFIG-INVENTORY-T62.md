## 2. 設計

### 2.1 切片 A：帳齡分組界線（M；建議先做）
- 新設定群組 `ar_aging`（設定中心，非敏感，`risk=ops`）：`edge1`＝30、`edge2`＝60、`edge3`＝90（整數）。限制：`1 ≤ edge1 < edge2 < edge3 ≤ 365`，**桶數固定 4**；讀取時再驗一次（不合法 ⇒ 用預設，並記 warning；不丟例外）。
- 單一讀取函式 `helpers/report_config.ar_edges()`；`_compute_ar_aging()`、Excel／PDF、前端全部改吃它。
- **鍵與標籤**：預設界線時維持今天的 `"0-30" "31-60" "61-90" "90+"` 與 `0–30 天…`（逐字相同）；改過界線時依界線產生（`0-45`、`46-75`…）。每個桶另外多一個 `idx`（0–3）給顏色用；顏色改成依 `idx`（舊的鍵字串比對拿掉），天數字色改為「超過 `edge3` 紅、超過 `edge2` 橘」。回應多一個 `edges` 讓前端不必寫死。
- **口徑不開放**：錨點（報價日）、哪些案件／款項算應收、金額計算（`payment_item_amounts`）、說明字。
- 影響範圍：所有人看到的報表分組變了，但**金額與筆數的合計不變**（只是歸桶）。屬 `loosen="up"`？— 否：它不放寬任何權限或金額可見性，列為一般設定（立即生效、留變更明細）；`impact_scope` 寫明「只改分組，不改合計」。
- 關閉（沒設過）⇒ 輸出逐位元相同；守門題：預設界線下 `_compute_ar_aging()` 的整包回應與舊版相同（`edges` 為新增鍵，故用『舊鍵子集相等』比對並明說）。

### 2.2 切片 B：工作表選擇（L；沿用 BP-3 匯出範本）
- 在 `helpers/export_templates` 的註冊表加一種能力 `sheets`：註冊 `reports:financial` 時帶工作表目錄 `[{id, label, required?, money?, optional_when?}]`（上表 13 張；`required`＝執行摘要）。範本新增鍵 `sheets: [id…]`（**只能選目錄裡的 id、順序固定＝目錄順序、至少含必選**）。
- 渲染：`_build_excel` 在建每一張表前問 `ET.sheet_enabled("reports:financial", id)`；沒範本／旗標關 ⇒ 全部建立（今天）。PDF 段落與月報郵件附件**跟著同一份設定**（同一份資料來源，避免 Excel 有 PDF 沒有的混亂）；若 PDF 要獨立設定則另開 `reports:financial-pdf`（待裁示）。
- 治理：移除工作表＝收緊；重新加回＝放寬（金額類工作表標 `money`，加回必須第二位核准，與 BP-3 欄位規則一致）；工作表名稱／內容不可改（標題文字不開放，避免與官方字樣混淆）。
- 預覽：依選定使用者（可見金額與否）列出『會出現哪些工作表、各有幾列樣本』，不產生實際檔案。
- 不涵蓋：工作表內的公式、合計列、數字格式、欄位計算。

### 2.3 切片 C：簡單工作表的欄位選擇（L；之後）
只開 3 張『純列表』工作表（未收款清單、案件清單、帳齡分析）的欄位：沿用 BP-3 的欄位目錄（`money` 欄位在輸出端再驗 `quote_money_visible`），標題可改名、順序可換、可省略（至少 1 欄）；帳齡分析的「帳齡區間」「應收金額」為必選。其餘工作表欄位不開放。

## 3. 風險與守門
- 三份界線副本（後端 Excel／PDF、前端）必須同時改，否則顏色與分桶不一致 ⇒ 守門題掃描：原始碼不得再出現 `> 90`／`> 60`（帳齡區域）與 `== "90+"` 字樣。
- 切片 B 的『關掉工作表』不得影響資料匯出的完整性稽核：每次報表匯出的稽核紀錄多記一個欄位 `sheets`（實際輸出的工作表）。
- 報表金額可見性規則不變（`_require_reports_access` ＋ `quote_money_visible`）。
