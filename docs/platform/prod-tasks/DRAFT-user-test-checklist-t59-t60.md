# 使用者驗收清單（草稿）：第 59 班、第 60 班上線後要試什麼

> 給正式機 Claude 轉交使用者用。**草稿，尚未在真瀏覽器逐項驗過**；畫面上的字若和這裡不同，以畫面為準並回報。
> 寫法：每一項「操作」一行、「應該看到」一行。**「不能變」**是最重要的——旗標關著時，畫面、檔案和今天要完全一樣。

## 先看這個（開關的規則）
- 這一批的新功能**全部有開關，預設都是關的**。上線後什麼都不用做，畫面應該和今天一模一樣。
- 開關在「系統 → 設定中心」。**只在『開發／驗證用的副本』打開來試，不要在正式機打開。**
- 想試「開了之後」的功能時：先到設定中心把下面「開關」那一列打開，試完**關回去**。
- 兩個功能需要**兩位最高管理者**才能完整試：放寬類的變更（例如新增欄位）會變成「待第二位核准」。
- 試的時候請用兩個帳號：一個**最高管理者**，一個**只有少數權限的一般同仁**（用來確認「沒權限的人還是看不到」）。

| 功能 | 設定中心裡的名稱 | 預設 |
|---|---|---|
| 版本帳本與影響預覽 | 建構器治理（版本帳本與發布前影響預覽） | 關 |
| 調整側欄選單 | 選單建構器 → 開放調整選單名稱與分組 | 關 |
| 頁面版面（欄位顯示／順序／名稱） | 自訂畫面版面 → 供應商管理頁／案件管理頁／採購管理頁／設備登載頁／承攬商管理頁 | 關 |
| 內建畫面加自己的欄位 | 自訂欄位（內建畫面） | 關 |
| 自訂按鈕 | 自訂按鈕 | 關 |
| 自訂匯出格式 | 自訂匯出（**同時要開「建構器治理」才會生效**） | 關 |

## 第一部分：第 59 班（所有開關都關著就能試）

### 1. 案件資訊存檔，不再誤報「已被他人更新」
- 操作：打開一張案件 →「案件資訊」分頁 → 改任一欄（例如備註）→ 按儲存；**馬上再改一次、再按儲存**，連續三次。
- 應該看到：每次都顯示「已儲存」；**不會**跳出「這筆資料已被其他人更新」。
- 不能變：欄位內容、金額、其他分頁都和存檔前一樣；重新整理後內容是你最後存的。

### 2. 叫料單（材料申請）存檔，同樣不誤報
- 操作：案件 →「叫料單／材料」→ 改一筆材料數量或備註 → 儲存；馬上再改再存，連續三次。
- 應該看到：每次都儲存成功，沒有「已被他人更新」。
- 不能變：數量、金額、狀態和你輸入的一樣；沒有出現不屬於你改的內容。

### 3. 案件清單（卡片）看起來沒變
- 操作：打開「案件管理」頁，捲動清單。
- 應該看到：和上線前一樣的卡片、同樣的欄位順序、金額欄位（沒有金額權限的帳號仍是「—」）。
- 不能變：卡片多或少任何欄位、按鈕、排序；沒有金額權限的帳號**看不到任何金額**。

### 4. 供應商頁沒變
- 操作：打開「供應商管理」頁，開一家供應商的編輯視窗，再關掉。
- 應該看到：清單欄位、工具列按鈕、編輯視窗和上線前完全一樣。
- 不能變：視窗最下方**沒有**新的「自訂欄位」區塊；工具列沒有多出任何按鈕。

### 5. 側欄選單沒變
- 操作：用最高管理者登入，看左邊側欄；再用一般同仁登入看一次。
- 應該看到：項目名稱、分組、順序和上線前相同；一般同仁看不到他沒權限的項目。
- 不能變：側欄角落**沒有**「調整選單」按鈕。

### 6. 下載與匯出照舊（旗標關）
- 操作：匯出「每日任務歷程 CSV」、「外包名冊 Excel」、任一張「開票申請憑據 PDF」。
- 應該看到：檔名、欄位、標題、順序和上線前一樣；PDF 沒有多出任何頁尾或浮水印。
- 不能變：欄位數量與順序。

## 第二部分：第 60 班（先確認「關著＝沒變」，再在副本打開來試）

### A. 旗標關著：全部確認一次「沒有新東西」
- 操作：用最高管理者逐頁看：案件資訊、供應商編輯、側欄、採購管理、設備登載、承攬商管理、簽核佇列。
- 應該看到：沒有「編輯版面」以外的新按鈕、沒有「自訂欄位」區塊、沒有「調整選單」、沒有「匯出格式」、沒有新的工具列按鈕。
- 不能變：任何頁面的載入速度或顯示內容；這幾頁和上線前截圖逐項一致。

### B. 版本帳本與影響預覽（先開這個，其他功能需要它）
- 操作：設定中心 → 建構器治理 → 選「開啟」→ 儲存；再打開任一個有「編輯版面」的頁面。
- 應該看到：編輯面板多出「版本帳本」，可列出每一版、比較任兩版、還原；發布前有「影響預覽」。
- 不能變：已經發布的版面和資料；只是多了檢視與預覽。
- 試完：改回「關閉」，確認「版本帳本」消失。

### C. 側欄「調整選單」（需先開：選單建構器）
- 操作：設定中心 → 選單建構器 → 開啟；側欄會出現「調整選單」→ 把某個項目改名（例如「供應商」→「廠商」）→ 按「預覽」。
- 應該看到：預覽顯示改名後的整份側欄；**要先預覽才能按發布**；改一次內容就要重新預覽。
- 操作：發布後重新整理，再用一般同仁登入看側欄。
- 應該看到：名稱已改；一般同仁只看得到自己有權限的項目；點進去的頁面和權限都沒變。
- 不能變：項目的連結、誰能進去；沒權限的人**仍然看不到**那個項目（改名不會讓人看到不該看的）。
- 若同時開著「建構器治理」：發布若屬於放寬，會顯示「已送出，待第二位最高管理者核准…」，**核准前選單不會變**。
- 試完：把名稱改回去或用「版本帳本」還原；再把開關關回去，確認「調整選單」消失、名稱回到原樣。

### D. 頁面版面編輯（需先開：自訂畫面版面 → 該頁）
- 操作：開啟其中一頁的開關（例如供應商管理頁）→ 回到該頁 → 最高管理者按「編輯版面」。
- 應該看到：右側出現編輯面板，改動（隱藏／改名／換順序）**立刻在畫面上預覽**，按發布前不會影響別人。
- 操作：把一欄改名後發布，再用一般同仁登入看同一頁。
- 應該看到：欄位名稱已變；一般同仁看到的欄位仍以他的權限為準。
- 不能變：金額欄位——沒有金額權限的帳號，無論怎麼設定版面，都**不會**看到金額。
- 若開著「建構器治理」且改動屬放寬（例如把隱藏的欄位顯示出來）：顯示「待第二位核准」，核准前不生效。
- 試完：用「版本帳本」還原，關掉開關，確認該頁回到原樣。

### E. 內建畫面加自己的欄位（需先開：自訂欄位（內建畫面））
- 操作：案件資訊分頁最下方（或供應商編輯視窗最下方）→ 最高管理者按「編輯自訂欄位」→「＋ 新增欄位」，填名稱（例：現場工頭），型別選「文字」。
- 應該看到：畫面上即時出現預覽（標示「預覽（草稿，尚未發布）」），這時其他人還看不到。
- 操作：按「存草稿」→「看差異」→「發布」（會問一次確認）。
- 應該看到：發布後，所有內部同仁在同一個畫面都看得到並能填寫；填一個值、存檔、重新整理，值還在。
- 不能變：這個欄位**不會**出現在報價單、客戶版文件、結案報告或回簽頁；沒有金額型別。
- 操作：停用這個欄位。
- 應該看到：畫面不再顯示，但先前填過的資料還在（重新啟用就回來）。
- 試完：關掉開關，確認區塊消失、舊資料不被刪除。

### F. 自訂按鈕（需先開：自訂按鈕；目前只有供應商管理頁工具列）
- 操作：供應商管理頁 → 最高管理者按「自訂按鈕」→「＋ 新增按鈕」→ 選「開啟頁面」或「執行匯出」→ 填按鈕文字 → 按「預覽」。
- 應該看到：預覽的按鈕出現在工具列（預覽中的按鈕不能點）；有「以某位使用者預覽」可以看別人會不會看到。
- 操作：用「以某位使用者預覽」選一位**沒有權限**的同仁。
- 應該看到：這顆按鈕對他是「不會出現」，並說明原因。
- 操作：發布後，用沒有權限的同仁登入看供應商頁。
- 應該看到：他的工具列**沒有**這顆按鈕；有權限的人才有。
- 不能變：按鈕只是入口，不會寫入任何資料，也不會讓人匯出他本來不能匯的東西。
- 試完：移除按鈕或還原，關掉開關。

### G. 自訂匯出格式（需先開：建構器治理 **和** 自訂匯出）
- 操作：到「簽核佇列」頁（開票申請憑據 PDF）或每日任務頁 → 最高管理者看到左下角「匯出格式」→ 打開。
- 應該看到：只能從清單挑欄位、換順序；頁首／頁尾／浮水印**只能從預設文字挑**（內部資料、機密、草稿、僅供參考…），沒有自由輸入。
- 操作：每日任務頁 → 拿掉「回報內容」欄、調換兩欄順序 → 預覽 → 發布 → 匯出歷程 CSV。
- 應該看到：匯出的檔案欄位與順序和你設定的一樣；沒有權限看的欄位不會出現在預覽。
- 操作：簽核佇列頁 → 開票申請憑據 PDF 加「頁尾：內部資料」→ 預覽 → 發布（會顯示待第二位核准）→ 第二位核准後下載一張憑據 PDF。
- 應該看到：PDF 底部有小字「內部資料」；**未核准的憑據仍然有紅色「尚未正式核准」橫幅，完全可讀**；金額、公司抬頭、簽核欄和原來一樣。
- 不能變：資料本身（誰能看到什麼）；PDF 的內容、金額、頁數。
- 操作：試著在 PDF 浮水印選項找「正本」「已核准」之類的字。
- 應該看到：**找不到**（系統不允許這類官方狀態字樣）。
- 試完：關掉自訂匯出，重新匯出同一份：欄位與 PDF 回到原樣。

### H. 匯出檔不會被「公式」搞怪（旗標關著也要試）
- 操作：在副本新增一筆客戶（或案件、外包人員）名稱填 `=1+1`，再匯出對應的 Excel／CSV 並用 Excel 打開。
- 應該看到：儲存格顯示的是**文字** `=1+1`（前面可能多一個看不見的單引號），**不會**變成 2、也不會跳出安全警告。
- 操作：外包人員電話填 `+886 2 1234 5678`，匯出外包名冊。
- 應該看到：電話原樣顯示，**沒有**多出可見的單引號。
- 不能變：一般文字、數字、金額、日期的顯示；負數仍是數字（可以加總）。
- 操作：把剛匯出的外包名冊 Excel 原封不動匯入回去。
- 應該看到：匯入成功，名稱沒有被加上多餘符號。

### I. 客戶、料號、供應商三頁的「匯出 Excel」
- 操作：旗標關著：在這三頁各按一次「匯出 Excel」。
- 應該看到：檔案照常下載，和以前一樣；沒有任何新的提示。
- 操作：（副本，開著建構器治理與自訂匯出）再各按一次。
- 應該看到：檔案照常下載；連按幾次也不會被擋；稽核紀錄裡多一筆「匯出」。
- 不能變：沒有權限的帳號看不到這三個頁面的資料。

## 回報方式
- 每一項請回「通過」或「不一樣」；不一樣就附上畫面截圖與你按了什麼。
- 看到「這筆資料已被其他人更新」、**任何**金額出現在不該出現的人面前、旗標關著卻出現新按鈕或新欄位——這三種請**立刻停手回報**。
