# M2 班更新摘要（給使用者；草稿）

> 基準：凍結樹 `train/m2-int-r9` `c87079be2343ef5596a14f50bdaaa45810007caf`（= r6 `9f7a63e99`＋1 個探針 commit）；包名與雜湊在發布時產生，見步驟檔。

## 結論

**M2 班可上線（待凍結與最終稽核）。正式機從 M1-a（`4eb52138`）更新到 M2。**
- 更新方式：正式機 Claude 自動套用，套用前自動備份並驗證；服務會重啟一次、使用者被登出一次。
- 資料庫：**只新增、不改不刪**。核心 schema 維持 118；新增 7 張表（設定變更 2、權限矩陣 5），新增的表一律是空的。
- **畫面上你會看到的變動只有三處**：報價單欄位改名、導覽列「系統」收成單一入口、新增唯讀的「設定中心」。金額、毛利、簽核、權限都不變。

## 你會看到的變動

1. **報價單「售後服務」改名為「售後服務及備註說明」**：表單、條款組管理、列印與 PDF 同步；只改顯示名稱，舊資料不動。表單版本 V3.22。
2. **導覽列「系統」變成一個入口**：點進去是索引頁（分組＋搜尋，只列你有權限的項目；「權限設定」標「規劃中」）；各系統頁網址不變，頁首多「← 系統」。不改變任何人看得到或做得到什麼。
3. **新頁「設定中心」（僅最高管理者、唯讀）**：列出 4 組設定（變更確認期間、備份與保留、上傳限制、系統中心顯示），目前值＝原本的設定；**沒有編輯畫面**。
4. **備份保留縮短改為「待生效」**：在「公司資料設定 > 備份與保留」把保留天數縮短，**不會立即生效**：改走設定登錄的待生效流程，預設 7 天確認期間、期間可撤銷，並需另一位最高管理者核准（只有一位最高管理者時：原因＋等待期＋警告＋通知）。稽核紀錄保留天數不得低於 365。變長或不變仍即時儲存。

## 看不到、但本班一併上線的

- 權限矩陣地基（無畫面；唯一端點是只回 ok 的唯讀狀態探針，不含任何權限資料；預設行為與今天逐字相同；5 張空表）。
- 設定變更明細（只增不改不刪），納入每日備份。
- 測試修復與守門（`test_fail_stream_aborted` 計時競態，只改測試）。

## 本班沒有的東西（請勿期待）

- 設定中心不能編輯；沒有權限勾選頁；擇一方案報價與派發下拉補丁屬 M3。
- 毛利率顏色門檻、轉簽規則等仍寫在程式裡。

## 需要你做的（驗收）

依序：**ca** 欄位改名、**cb** 系統中心、**cc** 設定中心唯讀、**cd** 備份保留縮短、**ce** 一切照舊。細節見步驟檔「需要使用者自己做的」。
- 🔴 **cd 會寫資料**：測完務必把該項**改回原值再儲存**；沒撤銷的縮短 7 天後自動生效，會更早刪除備份或稽核紀錄（不可逆）。須在正式機 Claude 完成步驟 3 #19 的稽核檢查之後才做。

## 任何一項不如預期即阻擋

選單或權限與昨天不同；非最高管理者看得到設定中心；設定中心數字與昨天不同；系統底下某頁打不開或缺「← 系統」；任何金額或管銷數字不同；備份保留縮短後立刻生效。
