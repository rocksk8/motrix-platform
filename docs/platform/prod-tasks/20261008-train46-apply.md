## 這一班有什麼（使用者看得懂的版本）

**A. 勞報單送審與簽核（第 46 班 P1）**（`wip/t46-payslip-impl-r1`）
- 勞報單多了「**送審 → 核准／駁回**」流程（獨立流程，不併入報價單／出貨單的統一簽核鏈）：草稿 → 待審核 → 已核准 → 匯出 → 簽回 → 付款。**既有草稿也要走新流程**（送審並核准後才能匯出）。待審核期間單據鎖定（不可編輯、不可刪除），駁回後可改再送。
- **簽核佇列的勞報單詳情**：不含金額、受領人、身分資料；**身分證字號與銀行帳號**只在抽屜裡「點選才顯示單欄」，且僅真正的最高管理者（superadmin）、僅待審核單、**每次顯示都寫一筆稽核 `payslip.approval_reveal`（不含值）**、先寫稽核失敗即不顯示、每分鐘上限 30 次。不進列表、計數、信件、通知、日誌。
- 6 種信件＋站內通知（送審／核准／駁回等）；內容不含金額、受領人、身分資料。

**B. 勞報單進出納（第 46 班 P2）**
