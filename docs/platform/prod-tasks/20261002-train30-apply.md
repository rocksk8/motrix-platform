## 需要使用者自己做的（先看，不要為了測試改正式資料）
1. **公告**（會影響使用者看到的數字）：①營運報表／案件頁外包總成本：之後新增的「草稿」「已退回」派發不計入，「待審核」計入並標示；②傳票摘要的承攬商成本**不再列出已取消的派發**；③匯款申請與總帳要求派發已核准（**舊派發不受影響**）。上線當天沒有任何既有派發會被改變狀態或改變金額計入（步驟 3 #9 已核對）。
2. **確認簽核人選**：派發審核預設走「統一簽核流程」（與報價單、出貨單同一條鏈）。請到「簽核設定」確認這條鏈的簽核人適合簽派發；不適合就在套用範圍取消勾選「承攬商派發」改設獨立流程。**統一流程若沒有任何簽核層，新派發送審會直接核准**。
3. 開案件頁「承攬商」分頁（只看，不要送審）：舊派發有灰色「舊單（未經審核）」徽章，原本的按鈕（待驗收、確認驗收）照舊可用；「新增派發」視窗沒有「狀態」欄；外包總成本旁在有待審核派發時才會出現「含待審核」。
4. 簽核佇列：沒有待簽派發時外觀不變；之後有人送審才會出現「承攬商派發」卡片。
5. 以非最高管理者看勞報單：帳號顯示 `****末四碼`、PDF 沒有存簿影本；最高管理者看完整（只看）。
6. 有待簽單據的帳號登入：「我的工作」標題有紅點、通知橫幅數字與簽核佇列頁一致；一般使用者（非管理員）也應看得到（只看，不要為了測試核可正式單據）。
7. 每日任務頁外觀應與上一版相同；檔案中心搜尋結果主按鈕為「開啟檔案」。
8. 已知：通知信（`dispatch_*` 八種）的收件偏好在「個人通知偏好」可調。
