# MS1b 完工單帶入報價項目班更新摘要（給使用者；草稿）

> 基準：凍結樹 `train/ms1b-int-a`（待填 SHA），在 MS1 上線版之上；包名與雜湊在發布時產生，見步驟檔。**版本號、筆數等凡標「以 CHANGELOG 定稿」者，凍結時才核對，現在不採信。**

## 結論

**MS1b 是一個小班：完工單可以從報價單帶入項目（不含金額）。可上線（待凍結樹閘門與最終稽核）。**
- 更新方式：正式機 Claude 自動套用，套用前自動備份並驗證；服務會重啟一次、使用者被登出一次。
- 資料庫：**預期沒有結構變動**（沒有新表、沒有新欄位）；部署本身**不寫任何設定值**。
- **預設不改變任何既有完工單**：舊單的內容、列印與今天完全相同。

## 你會看到的變動

1. **新建完工單自動帶入報價單項目**（品名、數量、單位；品牌可加在品名前）；**絕不帶入、也不顯示任何金額**。每列可改可刪，按「儲存」才寫入。
2. **「報價／已完工」小字**：分批完工時預設只填剩餘未完工的數量。
3. **「從報價單帶入」差異視窗**：完工單已有項目時，逐項勾選新增／移除／更新數量，沒勾的不動；報價單有更動時出現橫幅，要重新帶入才同步。
4. **只有「已送出」的報價單可帶入**；客戶尚未回簽預設可帶入但會提示；**擇一方案報價只帶入客戶已選定的品項**，未選定的組別會提示、不帶入。
5. **數量超過報價**預設只警示（標黃色，仍可儲存）。
6. **設定中心新增一組「完工單」**（7 項，預設照你 10-12 的裁示），設定中心由 8 組變 9 組。
7. **仍僅管理員能建立完工單**（放寬給業務屬另案權限審查，不在本班）。

## 本班沒有的東西（請勿期待）

- 業務建立完工單、自訂欄位、規則等平台建構積木。
- 脊柱 E-b 的後續基礎隨本班進場，但使用者看不到。

## 需要你做的（驗收）

依序：**A** 設定中心 9 組（唯讀，不要改設定）、**B** 一般報價單帶入（無任何金額）、**C** 差異視窗、**D** 分批完工只填剩餘、**E** 數量超過只警示（**不要把設定改成「擋下」**：改回需第二位最高管理者核准並等確認期）、**F** 報價單狀態與更動橫幅、**G** 擇一方案只帶已選定、**H** 業務仍被拒絕。**B～G 會寫資料，請用測試案件與測試報價單，做完刪除或取消。**細節見步驟檔「需要使用者自己做的」。

## 任何一項不如預期即阻擋

完工單出現任何金額；非管理員能建立完工單或帶入；未選定的擇一組別被帶入；未送出的報價單能帶入；差異視窗沒勾的項目被改動；舊完工單內容與昨天不同。

## 閘門結果

由整合者於發布時補入（full-lint、not_e2e、e2e、建包、驗證、演練與非作者稽核）。

## 回滾

預期沒有結構變動，程式可單獨回退到 MS1；**注意**：完工單設定群組裡改過的值，與已寫入完工單的帶入欄位仍留在資料庫，舊程式會忽略它們（資料保留）；待生效項目也會留在資料庫；是否回滾、是否還原資料庫由您決定，正式機 Claude 不自行回滾。
