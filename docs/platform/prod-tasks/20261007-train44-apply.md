## 這一班有什麼（使用者看得懂的版本）

**A. 站內通知鈴鐺（所有角色）**（`wip/t44-inapp-bell`）
- 鈴鐺**開放所有角色**（原本只有管理員看得到）；未讀數字每個人都顯示；點通知＝標已讀並直接開到該張單據（通知帶連結）。管理員原有的鈴鐺與「查看全部操作紀錄」不變。
- **站內通知保留 90 天**（已讀、未讀都清；每日與啟動時分批清理）。
- 核准類通知（type 以 `_approved` 結尾）同一張單、同一個人只留一則（去重）；報價單最後一層核准時，申請人收到站內通知。
- 通知文字裡的金額一律由伺服器遮成「（金額略）」，除非收件人有財務金額檢視權（不靠各呼叫端）。

**B. 簽核結果通知申請人**（`wip/t44-applicant-notify`、`wip/t44-bonus-mail`）
- **所有簽核流程的信件主旨與標題都寫明結果**（已核准／已退回／待審核／輪到您審核／待付款／已付款）；「我的申請」新增**單號**欄；站內通知含單號與連結。
- **補齊申請人信**：舊式簡單額外支出、額外支出變更申請、完工單核准或被退回後，申請人會收到信；承攬商派發信件主旨也寫出結果。
- **獎金分潤**：簽核完成（核准、進入待發放）時送審人收到「獎金分潤 單號 已核准」；駁回／退回（回草稿）時送審人收到「已退回」（附原因）；信與站內通知都**不含金額**；兩種信可在個人通知偏好退訂。送審人就是操作者本人時不重複寄。

**C. 採購單從請購單帶入**（`wip/t44-pr-to-po`）
- 採購單明細可連到同案件**已核准**請購單的明細：一張採購單可混合多張請購單，數量可部分（上限＝請購項目剩餘量，分次累計不超過請購量）；單價預設複製請購單、可修改，與請購單不同時標示。
- **權限／遮蔽**：看不到財務金額的人（例如管理員）**不會被複製請購單單價**（不回 `unitCost`），金額被遮蔽的請購單不列在挑選器。
- 採購單作廢、駁回、退回會釋放已認領量；**已被採購單認領的請購單不能作廢（409）**；已核准請購單的變更申請不得刪除／改品名／把數量改到低於已認領量。

**D. 支出申請附件**（`wip/t44-multi-attach`、`wip/t44-attach-views`）
- 新增支出申請頁的附件改為**累加挑選**（每次挑的檔加進清單）；伺服器端上限：**每張最多 10 個附件、單檔 20 MB、一次送出合計 50 MB**；接受 jpg／png／pdf／HEIC（HEIC 只提供下載、不內嵌預覽）。附件被擋時草稿已建好，重按沿用同一張草稿、只補傳附件（不會重複建單）；**刪除草稿／已駁回的申請會一併清掉實體檔案**。
- **權限規則**：申請人與管理員只能在**草稿／待審核（簽核中）／已駁回**狀態增刪附件；**財務在待審核／簽核中可補發票**；**簽核人唯讀**；核准後鎖定（只能補發票）；作廢保留檔案。「我的申請」可增刪附件。
- **簽核與出納唯讀看附件**：簽核頁附件分「發票／附件」顯示、含大小；**出納待付款申請清單**可看每個附件的名稱與大小並開啟（唯讀）。
- **行為變更（請知悉；使用者 2026-10-07 裁示）**：
  1. 附件視同金額：**看不到金額的人**（例如不是該單簽核人的管理員、非財務）在簽核詳情**看不到發票／收據檔案**；簽核人與財務不變。
  2. **舊筆（附件沒有 kind、單據 kind 為空）也套用同一條規則**（舊單據對看不到金額的人不再顯示檔案）。
  3. **已登錄付款的單據，出納不能再在待付款清單開附件**（改走原單據頁）。
  4. 下載／開檔失敗改頁內訊息，不再跳瀏覽器對話框。
  5. 出納開啟附件**每次留稽核紀錄**（`cashier.payable_file_view`，不記內容）。
  6. 「我的申請」多一欄**單號**。
