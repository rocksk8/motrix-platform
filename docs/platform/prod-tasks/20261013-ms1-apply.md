## 這一班有什麼（使用者看得懂的版本）
**A. 設定中心編輯器（S1；僅最高管理者）**：M2 起設定中心是唯讀，本班起管理者可以**在畫面上直接修改設定**（含 M3 擇一方案政策與文字）。
- 每個設定有「**影響預覽**」：改之前先看會影響什麼；放寬類（把限制變鬆）會出**紅色提示**，並需要**第二位最高管理者**核准才生效；收緊類單人即可。
- **版本與還原**：每次修改都留下版本，可看差異（diff）、可還原到舊版；修改前系統自動留快照。**重設為預設**可單項執行。
- 新增端點（皆需登入、僅最高管理者）：影響預覽、重設、版本清單、差異、還原等（`FILL_MS1_ROUTES`，以 CHANGELOG 為準）。
**B. 功能狀態與灰卡（E-a／E-b 骨架）**：系統中樞的功能卡片有狀態「開放／規劃中／隱藏」。**規劃中的功能顯示為灰色卡片，標示「規劃中 MSn」，點了不會進入、也不會出錯**；隱藏者不顯示。狀態只控制「能不能編輯、發布、顯示」，不改變既有功能的權限。目前哪些卡片是灰的：`FILL_MS1_GREY_CARDS`（以凍結樹 module.json 的 `features[]` 為準）。
**C. 下載檔名規則（A7）**：下載的檔名改為統一規則（可在設定中心群組「下載檔名」調整，共 21 個設定項）。報價單、案件附件等下載檔名會與今天不同，範例：`FILL_MS1_NAME_EXAMPLES`。**已封存版本的下載也會依新規則改名**（舊檔不動，只是下載時的檔名改變）。檔名上限 255 位元組，超長會自動截短。
**D. 專案毛利％（候選；是否隨本班以 CHANGELOG 為準：`FILL_MS1_MARGIN_INCLUDED`）**：新增設定群組「專案毛利」與唯讀端點 `GET /api/project-margin/config`；預設值＝今天的口徑。若未隨本班，本段與驗收 H 一併刪除。
**E. 開發端（正式機無感）**：測試、產生檔、文件登記、建包工具的小修。
