## 這一班有什麼（使用者看得懂的版本）
**A. 修正：在案件頁編輯材料申請清單後存檔，不再誤跳「已被他人更新」（`case` `1.0.184`）**：
- **現象**：自己改過材料申請清單後再存一次，偶爾被當成「別人更新過」而擋下（409）。原因是伺服器存檔時會改寫材料卡片（認列的到貨人／時間、過期標記、被拒還原），畫面卻只以送出的內容當比對基準。
- **本班修正**：案件資料的分段存檔與叫料單存檔成功時，伺服器回傳實際存入的內容（`saved`），畫面以它當新基準，沒被動過的卡片也一併換成伺服器版。舊畫面忽略新欄位。
- **附帶**：材料卡片『帶入並連結』存檔失敗時，提示文字如實改為「認列尚未儲存：請看畫面上方的儲存狀態；按「儲存」或再編輯一次會重新送出」（原文寫「會自動重試」不正確）。
