## 這一班有什麼（使用者看得懂的版本）
**PDF 安全性修正（熱修）**：修正報價單、出貨單、請款單、案件結案報表等 PDF 在產生時的一個資安漏洞——有人若在品項數量、有效日數、款項百分比、階段日期這類欄位填入特殊內容，過去有機會讓伺服器把本機檔案或網路請求放進 PDF 的產生過程。本次一方面把這些欄位的內容一律當成純文字處理，另一方面讓 PDF 的產生程序不再允許載入外部檔案、頁框與對外連線（頁面本來就有的版面縮放腳本與圖片、傳票附件圖片照常運作）。

怎麼確認：開一張正常的報價單與出貨單 PDF，版面、文字、圖片、頁數都應該和更新前一樣；除此之外沒有任何功能或畫面改變，也不需要重新設定任何東西。

> 注意（請勿誤解為已完全封死）：本班的主要防護是把欄位內容一律當純文字處理（堵住已知的五個輸出點）；PDF 程序的外部載入與對外連線限制是補強。**頁面內被注入的 script 與頁面導向在本班仍未被完全擋住**，後續 H2（第 62 班）會再補。

技術範圍（供核對，不需要使用者操作）：僅 `backend/pdf_gen.py`（五個輸出點補逸出：品項數量、有效日數、款項百分比、階段期間，報價單／出貨單／結案報表／專案執行報告）與 `backend/helpers/startup.py`（`run_edge_pdf` 統一出入口：把內容安全政策〔CSP〕寫進要渲染的 HTML；Edge 加 `--disable-extensions`、`--disable-sync`、`--host-resolver-rules=MAP * ~NOTFOUND , EXCLUDE localhost`，旗標插在最後的 `file:///….html` 參數之前，既有旗標位置不變；硬化失敗 ⇒ 不渲染，記 log）。檔案路徑含 `#` 或 `?` 的情況在本班不特別處理（H2 才拒絕）；正式機 TEMP 路徑幾乎不可能含此字元。其餘為測試與文件。
