## 這一班有什麼（使用者看得懂的版本）
**A. 完工單可以從報價單帶入項目（`case` 1.0.180 → **1.0.181**；僅限管理員，與建立完工單同一道權限）**：
- 新建完工單時，可**自動帶入報價單的項目**（只有品名、數量、單位，品牌可選擇加在品名前；**絕不帶入任何金額**）。每一列都能修改、刪除，按「儲存」才會寫入。

- **擇一方案報價**：只帶入客戶**已選定**的品項；尚未選定的組別整組不帶入，並提示「尚有 N 組方案客戶還沒選定，該組品項沒有帶入」。
- **數量超過報價**時預設只警示（該列標黃色並顯示超過多少），仍可儲存。
- 新增端點（需登入、僅管理員、且報價單本體可讀）：`GET /api/completion-notes/quote-items`。
**B. 設定中心新群組「完工單」（`completion_note`，共 **7 個設定**）**：設定中心由 8 組變 **9 組**（`change_control`、`completion_note`、`download_name`、`material_order`、`project_margin`、`quote_alt`、`retention`、`system_hub`、`uploads`）。預設照使用者 10-12 裁示：新建時自動帶入＝是、未回簽可帶入並提示＝是、帶入數量＝只填剩餘、預設狀態＝完成、一併帶入分段標題＝是、品名前加品牌＝是、數量超過報價＝警示但可儲存。**部署不寫任何設定值。**
