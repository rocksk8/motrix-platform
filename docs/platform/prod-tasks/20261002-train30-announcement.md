# 第三十班上線公告（給使用者；草稿）

> 白話、簡短。上線當天**沒有任何既有資料被改動**：既有的派發維持原狀態、原金額、原計入方式。
> 內容與「套用步驟」（`20261002-train30-apply.md`）一致；數字與名詞以實際包為準。

## 這次有什麼不一樣

### 1. 承攬商派發：新增要先「送審」，核准後才能往下走
- **新增派發**後是「草稿（尚未送審）」。按卡片上的**「送審」**，依「簽核設定」的流程簽核；核准後才能「已送出 → 已確認 → 待驗收 → 確認驗收」。
- **完工也要審核**：驗收後按**「申請完工」**，審核通過才會變「完工」。不能再直接把狀態改成完工。
- **新增派發視窗沒有「狀態」欄了**：狀態只由卡片上的按鈕改。
- 退回會告訴你原因，修改後可再送審；送審中（還沒人簽）可以「撤回送審」。
- 每張新派發有單號（`DP-日期-流水號`），簽核佇列會出現「承攬商派發」「承攬商派發完工」，並寄通知信（信內不放金額）。
- 要請款或入帳：**派發要先核准**，才能開匯款申請、才會進總帳。

### 2. 舊的派發：標「舊單」，照舊使用
- 上線前建立的派發全部標示**灰色「舊單（未經審核）」**，**不用補審**，原本的按鈕（待驗收、確認驗收…）照舊可用，也照舊可以開匯款申請。
- 只有兩種情況會用到新規則：①舊單要**完工**，一樣要走「申請完工」審核；②舊單若**改了承攬商、品項、人員或稅率**，會回到草稿，要重新送審（改備註、日期、發票不受影響）。

### 3. 報表與成本的算法（數字可能和上個版本不同）
- **新增的「草稿」「已退回」派發不計入**外包成本；**「待審核」「簽核中」會計入**，並標示「派發待審核」／「含待審核 N 筆」；已核准與舊單照常計入。
- **傳票摘要的承攬商成本不再列出「已取消」的派發**（舊版會列出）。
- 影響範圍：營運報表、案件頁與精算頁的「外包總成本」、傳票摘要。上線當天既有派發的計入結果不變。

### 4. 待簽紅點與登入橫幅：一般使用者也看得到
- 輪到你簽核時，選單「**我的工作**」標題會出現**紅點**（數字與簽核佇列頁一致）。
- 登入後的待簽核橫幅、通知徽章，**非管理員也會顯示**（以前只有管理員看得到）。

### 5. 勞報單：收款帳號遮蔽
- 非最高管理者看勞報單詳情與 PDF，銀行帳號只顯示**末四碼**（`****1234`），PDF 不帶存簿影本；最高管理者看完整。
- 若你需要看完整帳號，請洽最高管理者。

### 6. 檔案中心：直接「開啟檔案」
- 搜尋結果的主按鈕改為**「開啟檔案」**（圖片、PDF 直接在新分頁開），原本的「開啟原單據」改成次要連結「前往原單據」。

### 7. 其他
- 每日任務頁預留「自訂頁籤」位置（沒有人設定時畫面不變）。
- 側欄通知元件修正重複初始化。

## 上線後請你做兩件事（各 2 分鐘）
1. 到「簽核設定」確認：**派發審核走的簽核人**適合（預設跟報價單、出貨單同一條流程；不適合可取消勾選「承攬商派發」改設獨立流程）。**若流程沒有設任何簽核層，送審會直接核准。**
2. 開案件頁「承攬商」分頁看一眼：舊派發是否顯示「舊單」、新增派發視窗是否沒有狀態欄。**不要為了測試去送審或核可正式單據。**

## 有問題請告知
- 看不到「送審」按鈕：確認該派發是「草稿」或「已退回」、且你有管理員權限。
- 舊派發要完工：請走「申請完工」。
- 勞報單看到末四碼想看完整：洽最高管理者。
