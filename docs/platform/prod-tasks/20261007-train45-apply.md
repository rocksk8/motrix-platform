b. **出納改預定付款日**（財務角色）：待付款清單挑一筆（額外支出、材料申請匯款、承攬商匯款各一）補登→改期→清除預定付款日；材料申請匯款若分次付款仍有餘額，可改下一次預定日；**已付款的離開待付款清單，畫面上改不到**（不要為了驗證而去付款或打 API）。**非財務角色**（業務、工程師）打不開這項操作。
