# M3 擇一方案報價班更新摘要（給使用者；草稿）

> 基準：凍結樹 `train/m3-int-a`（待填 SHA），在 M2.1 上線版 `41348ee6` 之上；包名與雜湊在發布時產生，見步驟檔。

## 結論

**M3 是新功能班：報價單新增「擇一方案」。可上線（待凍結樹閘門與最終稽核）。**
- 更新方式：正式機 Claude 自動套用，套用前自動備份並驗證；服務會重啟一次、使用者被登出一次。
- 資料庫：**沒有任何變動**（沒有新表、沒有新欄位）；核心版本 1.129 → 1.130（只增新名稱）。
- **預設不改變任何現有單據**：沒有勾「擇一」的舊報價單，金額、畫面、列印與今天完全相同。

## 你會看到的變動

1. **報價單可標「擇一方案」**：品項可填「擇一組別」（例：投影機有兩個品牌可選）；單據可勾「合計依方案選擇」（預設關）。勾了以後，合計只算非擇一項，成本分機標「暫估」，毛利率不顯示綠燈；備註自動出現「項次X、Y為〔組別〕擇一方案選擇」。
2. **成本比較面板**（只有具成本權限者看得到）：逐項列出稅前、成本、毛利、營業利益；組合比較預設收合。客戶版列印／PDF 不含成本、毛利字樣，合計兩格顯示「依方案選擇」。
3. **回簽時必須逐組選定客戶採用的方案**（您 10-11 的裁示）；選定後合計、毛利、案件頁金額、PDF 都改為所選方案。
4. **已回簽的報價本文預設鎖定**（不能改品項、金額、備註）；「取消回簽」會清除選定、金額回暫估，若案件已成案／已開票或請款／已精算會被擋並說明先處理哪一步。
5. **設定中心新增一組「擇一方案」**（共 8 項），預設照上述；**目前只能看、不能改**（設定編輯畫面要等後續班）。

## 本班沒有的東西（請勿期待）

- 設定編輯畫面、其他政策選項（P2②、P3②、P5②、P6②、P7②、P8② 顯示「尚未提供」）。
- 下載檔名、專案毛利%、完工單自動帶入、K01／K08／K10。

## 需要你做的（驗收）

依序：**A** 開單、**B** 成本比較（有成本權限者）、**C** 客戶版、**D** 回簽選方案、**E** 鎖定、**F** 取消回簽、**G** 不受影響（舊單與設定中心 6 組、不要改任何設定）。**A～F 會寫資料，請用測試報價單，做完刪除或取消。**細節見步驟檔「需要使用者自己做的」。

## 任何一項不如預期即阻擋

沒有勾擇一的舊單金額與昨天不同；沒有成本權限者看得到成本／毛利；客戶版出現成本字樣；已回簽的單仍可改金額。

## 閘門結果

由整合者於發布時補入（full-lint、not_e2e、e2e、建包、驗證、演練與非作者稽核）。

## 回滾

沒有資料庫變動，程式可單獨回退到 M2.1（`41348ee6`）；**注意**：若回退前已經有含擇一資料的報價單，舊程式不認得擇一欄位（資料仍保留），計算時可能把所有品項都計入金額——所以回退前請先與開發機確認；是否回滾由您決定，正式機 Claude 不自行回滾。
