# MS1 設定中心編輯器班更新摘要（給使用者；草稿）

> 基準：凍結樹 `train/ms1-int-a`（待填 SHA），在 M3 上線版之上；包名與雜湊在發布時產生，見步驟檔。**版本號、群組數、灰卡清單、檔名範例等凡標「以 CHANGELOG 定稿」者，凍結時才填，現在不採信。**

## 結論

**MS1 是「設定可以在畫面上改」的一班：設定中心由唯讀變成可編輯，並帶版本與還原。**
- 更新方式：正式機 Claude 自動套用，套用前自動備份並驗證；服務會重啟一次、使用者被登出一次。
- 資料庫：**預期沒有結構變動**（沒有新表；以凍結樹 CHANGELOG 為準）；部署本身**不寫任何設定值**。
- **預設不改變任何現有行為**：沒人去改設定時，系統與今天相同；下載檔名是唯一預設就會變的地方（見下）。

## 管理者上線後會看到

1. **可編輯的設定中心**（僅最高管理者）：每一項可直接修改。
2. **影響預覽**：改之前先看會影響什麼。**放寬類**修改出**紅色提示**，且需要**第二位最高管理者**核准才生效；收緊類單人即可。
3. **版本與還原**：每次修改留版本，可看差異、可還原（還原也留一筆新版本）；修改前系統自動留快照；可單項「重設為預設」。
4. **功能卡片狀態**：系統中樞卡片分「開放／規劃中／隱藏」；**規劃中的是灰色卡片，標「規劃中 MSn」**，點了不會進入、也不會出錯。
5. **下載檔名統一規則**：報價單、案件附件等下載檔名與今天不同；可在設定中心「下載檔名」群組調整（21 項）；**已封存版本下載時也會用新檔名**（檔案內容不變）。
6. （候選，是否隨本班見 CHANGELOG）設定群組「專案毛利」，預設＝今天口徑。

## 本班沒有的東西（請勿期待）

- 自訂欄位、版面、規則、匯出範本、流程等「平台建構」積木：**不在本班**（灰卡就是預告）。
- 修改設定不會自動通知他人；請用版本清單與稽核追溯。
- 沒有第二位最高管理者時，放寬類修改無法生效（設計如此）。

## 需要你做的（驗收）

依序：**A** 非最高管理者看不到編輯入口、**B** 改收緊、**C** 改放寬（紅色提示、停在待核准）、**D** 第二位最高管理者核准（同一人不能自核）、**E** 版本／差異／還原、**F** 重設為預設、**G** 灰卡、**H** 下載檔名（含已封存版本）、**I** 專案毛利（若包含）。**B～F、H 會寫設定，驗收完請還原到原值。** D 需要**第二位最高管理者帳號**；細節見步驟檔「需要使用者自己做的」。

## 任何一項不如預期即阻擋

非最高管理者能改設定；放寬類修改沒經第二位核准就生效；自己核准自己；還原後值不對；下載檔案內容與昨天不同；灰卡點擊報錯。

## 閘門結果

由整合者於發布時補入（full-lint、not_e2e、e2e、建包、驗證、演練與非作者稽核）。

## 回滾

預期沒有結構變動，程式可單獨回退到 M3；**注意**：回退前若管理者已修改過設定，這些值留在資料庫，舊程式可能忽略它們（資料仍保留）；是否回滾、是否還原資料庫由您決定，正式機 Claude 不自行回滾。
