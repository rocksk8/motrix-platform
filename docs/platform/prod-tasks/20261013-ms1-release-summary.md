# MS1 設定中心編輯器班更新摘要（給使用者；草稿）

> 基準：凍結樹 `train/ms1-int-a`（待填 SHA），在 M3 上線版之上；包名與雜湊在發布時產生，見步驟檔。**版本號、群組數、灰卡清單、檔名範例等凡標「以 CHANGELOG 定稿」者，凍結時才填，現在不採信。**

## 結論

**MS1 是「設定可以在畫面上改」的一班：設定中心由唯讀變成可編輯，並帶版本與還原。**
- 更新方式：正式機 Claude 自動套用，套用前自動備份並驗證；服務會重啟一次、使用者被登出一次。
- 資料庫：**預期沒有結構變動**（沒有新表；以凍結樹 CHANGELOG 為準）；部署本身**不寫任何設定值**。
- **預設不改變任何現有行為**：沒人去改設定時，系統與今天相同；下載檔名是唯一預設就會變的地方（見下）。

## 管理者上線後會看到

1. **可編輯的設定中心**（僅最高管理者）：每一項可直接修改。
2. **影響預覽**：改之前先看會影響什麼。**放寬類**修改出**紅色提示**，需**另一位最高管理者核准**，核准後還要等**確認期**（預設 7 天）才生效，期間可撤銷；**只有一位最高管理者時不需核准，但仍等確認期**。收緊類單人、立即生效。高風險設定被修改時，**其他最高管理者會收到站內通知**。
3. **版本與還原**：每次修改留版本，可看差異、可還原（還原也留一筆新版本）；修改前系統自動留快照；可單項「重設為預設」。
4. **功能狀態**：**設定中心**的群組可為「開放／規劃中／隱藏」；規劃中者是灰色卡片、標「開發中」，點了不會進入、也不會出錯；隱藏者不出現。**本班沒有灰色設定群組卡；設定中心側欄多一個「即將推出」區（只有最高管理者看得到）**，列出 10 筆預告（例：新增與調整畫面上的欄位、自訂匯出、調整單據流程…，每筆「開發中，預計 MSn 版提供」，點了沒反應、不含日期；以凍結樹為準），系統中樞顯示「開發中 10 項」；系統中樞原有的「規劃中」標籤與此無關。這是預告，不是已提供的功能。
5. **下載檔名統一規則**：報價單、案件附件等下載檔名與今天不同；可在設定中心「下載檔名」群組調整（21 項）；**已封存版本下載時也會用新檔名**（檔案內容不變）。
6. **專案毛利％**：報價單內部損益區與案件頁（財務可視者）新增「專案毛利％」（未稅收入扣未稅成本，不扣進項稅，所以不低於、通常高於直接毛利率；零稅或免稅時兩者相等）；只是讀取時計算、不改任何資料；沒有成本權限者看不到，客戶版不出現。報價單表單 V3.23 → V3.24；新設定群組「專案毛利」（提醒門檻預設 0＝不提醒）。

## 本班沒有的東西（請勿期待）

- 自訂欄位、版面、規則、匯出範本、流程等「平台建構」積木：**不在本班**（若有灰卡，就是預告）。
- 一般設定修改不會通知他人（高風險設定才通知其他最高管理者）；請用版本清單與稽核追溯。
- 只有一位最高管理者時，放寬類修改不需核准、但仍等確認期（可撤銷）。

## 需要你做的（驗收）

依序：**A** 非最高管理者看不到編輯入口、**B** 改收緊、**C** 改放寬（紅色提示、停在待核准）、**D** 另一位最高管理者核准（預期「已核准、待生效」＝通過，**驗完要撤銷待生效項**，否則 N 天後自動生效；同一人不能自核）、**E** 版本／差異／還原、**F** 重設為預設、**G** 即將推出、**H** 下載檔名（含已封存版本）、**I** 專案毛利％（測試報價單）。**B～F、H 會寫設定，驗收完請還原到原值。** C、D 需要**兩位最高管理者帳號**；細節見步驟檔「需要使用者自己做的」。

## 任何一項不如預期即阻擋

非最高管理者能改設定；放寬類修改沒經核准或確認期就生效；驗收後仍有未撤銷的待生效項；自己核准自己；還原後值不對；下載檔案內容與昨天不同；沒有成本權限者看得到專案毛利％、客戶版出現專案毛利％；灰卡（若有）點擊報錯。

## 閘門結果

由整合者於發布時補入（full-lint、not_e2e、e2e、建包、驗證、演練與非作者稽核）。

## 回滾

預期沒有結構變動，程式可單獨回退到 M3；**注意**：M3 已會讀已發布的設定值，M3 既有群組的值在只回退程式後**仍然套用**，只有 MS1 新增群組（下載檔名等）的值被忽略；待生效項目也會留在資料庫；是否回滾、是否還原資料庫由您決定，正式機 Claude 不自行回滾。
