## 這一班有什麼
- **簽核與會計**（`accounting` 1.1.15→1.1.39）：傳票最後一關固定由最高管理者核准（不改儲存的流程設定）；作廢已過帳傳票、科目與報表對應變更、取消繳庫只有最高管理者能做；期間結帳／重開／年度結帳／建立期初改為送審（待最高管理者核准後自動執行）；傳票與送審申請有信件；同時按過帳只會成功一次。
- **總帳功能**：預設仍全部關閉（最高管理者在「總帳作業」按開啟）；本班起「營業稅 401」「扣繳與補充保費」「來源憑證補登」可被開啟（401 欄位代號已改用財政部官方格式）；分錄草稿開啟後每小時自動產生；自動與獎金傳票不可直接作廢。

- **附件**：開檔要確認檔案屬於該單據（`/api/attachments/open` 重新開啟）；傳票「帶入來源附件」同樣綁定；案件儲存時丟掉不屬於該案的檔案路徑；**上線前請先掃描現有資料（步驟 1A）**。
