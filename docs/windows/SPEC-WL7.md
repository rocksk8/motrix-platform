## §5 處置

### 🔴🔴 ⓪ 先講：**改讀設定不夠 —— 內建預設值本身就是我們的公司**

```python

"tax_id":          "**60575481**",
"phone":           "**04-3610-6566**",
"email":           "**info@miactw.com**",
```
⚙️ 而 `:31` 的註解逐字寫著解析鏈：
> 「這一筆據點的欄 → 主要據點的同一欄 → `company_profile` 的同一欄 → **內建預設**」

> ### ☠️ **四層 fallback，而最後一層是我們的公司。**
> ### ⇒ 客戶只要**沒填**，PDF 上印的還是我們。

```
🔑 ⇒ 「改讀設定」這個修法**看起來會修好** ——
   開發機上我們填了自己的資料，所以改完看起來一模一樣 ✅
   ☠️ 而客戶那邊**沒有人填** => 落回預設 => **還是我們的公司**
📌 〈降級之後它還是會動〉：**成功而降低了正確性的那一種，沒有人會報修。**
⇒ ⇒ 處置**必須含**：把那四個預設值改成**空字串**
```

⚠️ 而改成空之後 PDF 會印空白 ⇒ **那是另一個要處理的**：
```
✅ 而 `_first_filled()` 已經是「**逐欄**落空」不是「整筆有值就整筆用」（`QL5`）
   => 空欄位不會拖垮其他欄位
🔴 而「印空白」與「印我們的公司」哪個好 —— **印空白**：
   ☠️ 印我們的公司 => 客戶拿著一份抬頭是別家公司的報價單去給他的客戶
   ✅ 印空白 => 他會發現，而他會去填
🔑 〈一個看得見的失敗，比一個看不見的成功好〉（`UP2 §4` 同一條）
```
