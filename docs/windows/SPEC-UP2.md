## §4 處置：**刪不掉就不要移除記錄**

```python
removed = True
try:
    if os.path.isfile(full):
        os.remove(full)
except Exception:
    logger.warning("刪除實體檔失敗：%s", full, exc_info=True)
    removed = False

if not removed:
    raise HTTPException(500, "檔案刪除失敗，請稍後再試（記錄保留）")
# 只有刪成功才移除記錄
```

### 🔑 判準：**哪一種殘留比較好收拾？**

```
記錄留著、檔案留著  => 使用者看得到它，**可以再按一次刪除**   ✅
記錄沒了、檔案留著  => 🔴 **沒有任何介面碰得到它**，而它會進備份
```

> ### ⇒ **一個看得見的失敗，比一個看不見的成功好。**

### ⚠️ 而「整個失敗」有一個代價要講出來

```
☠️ 檔案被鎖住（Windows 上另一個行程開著它）=> 使用者**刪不掉那一筆**
   而他會一直看到它
⇒ 兩種殘留裡，這一種是**他抱怨得出來**的那一種
🔑 而那正是判準：**抱怨得出來 > 沒有人知道**
```

### 🔴 而 `os.path.isfile(full)` 為 False 時**不算失敗**

```
檔案本來就不在（先前刪過／備份還原時漏了）=> **照常移除記錄**
☠️ 把它當失敗的話，一筆「檔案早就不見了」的記錄會**永遠刪不掉**
   => 那是這個修法自己會製造的新坑
⇒ 判準：**「刪失敗」與「本來就不在」是兩件事**
   📌 〈null 不等於 0〉的檔案版
```

### ⚠️ `helpers/uploads.py:113` 那一處改法不同

```
它是 helper，**回傳過濾後的陣列**，不是端點 => 它拋不出 HTTPException
⇒ 改成回 `(new_list, ok)` 或在刪不掉時 `raise` 一個自訂例外，
  讓 **27 個呼叫端**各自決定
🔴 而「讓 27 個呼叫端各自決定」有風險：**其中會有人吞掉它**
   ⇒ 所以要 `raise` 而不是回旗標 —— **忽略一個例外要多寫一行，忽略一個旗標不用**
   🔑 〈防護的副作用落在盲側〉：問「**它誤報時對方最省力的反應是什麼**」
```

## §5 驗收（`AC1`）

```
① 後端  4 處：刪檔失敗 => **不移除記錄**，回一個看得見的錯誤
        `helpers/uploads.py` 那支改成 raise，27 個呼叫端不可以吞
② 前端  刪除失敗時顯示一句話（不是靜默什麼都沒發生）
③ 頁面  ⓐ 把某個附件的實體檔設成唯讀／鎖住 -> 按刪除
           => 畫面說失敗，**且重整後那一筆還在**
           🔑 ⓐ 是核心 —— 改之前它會消失，而檔案留在磁碟上
        ⓑ 手動把實體檔刪掉（模擬「本來就不在」）-> 按刪除
           => **成功**，記錄移除
           ☠️ 少了 ⓑ，「一律當失敗」的實作會讓那一筆永遠刪不掉
        ⓒ 正常情況刪除 => 檔案與記錄都不見（**既有行為不可以壞**）
        ⓓ 負對照：產一次 PDF => `tmp` 檔清理失敗**不影響匯出**
           🔑 §3① 那一族不可以被這一件波及
```

## §6 守門

```
✅ 釘：「刪使用者檔案 ＋ 移除 DB 記錄」的動作裡，**刪檔的 except 不可以是 pass**
   ⚙️ 母體判準（`ast`）：同一個函式裡**同時**有
      ① `os.remove`／`os.unlink` 被 try 包住
      ② 一個 `DELETE FROM` 或「從 list 濾掉那一筆」的回傳
   ⚠️ 而**不要只掃 `except: pass`** —— 改成 `except: logger.warning(...)`
      照樣會走到下一行的 DELETE
      🔑 ⇒ 釘的是「**失敗之後有沒有中止**」，不是「有沒有記 log」
      ☠️ 那正是 `EM7` 剛學到的：log 不是落點

⚙️ 合法清單（**明碼列名，而不是讓它們掃不到**）：
   quotations.py:2293  `_cleanup_staged_files`（§3② 有逐字理由）
   `finally:` 區塊裡的暫存檔清理（pdf_gen／reports／network_plan_export）
   🔑 加總自檢：母體 = 要改 4 + 合法 N，而 N 要數得出來

🎣 誘餌（合成）：
   A  刪檔 except pass ＋ 緊接著 DELETE        => **必須亮**
   B  刪檔 except logger.warning ＋ DELETE     => **必須亮**（🔑 這是 B 的陷阱）
   C  `finally` 裡刪 tmp，沒有任何 DELETE      => **不可以亮**
   D  刪檔失敗有 raise／有 return             => **不可以亮**
```
