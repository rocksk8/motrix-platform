## §2 🔴 純裁示的那一格：**哪些舊單號是歷史事實？**

> A 2026-09-23 明著提出，而它**不是量測問題** ——
> 答錯的兩個方向都很貴：
> **改了＝竄改歷史 ／ 不改＝使用者搜舊單號搜不到。**

### 建議的判準（**沿用使用者已經裁過的那一條**）

`QL10`／`QL16` 那次使用者裁定的判準逐字是：

> 匯款帳號要回答「**現在**該匯到哪」，而薪資單的抬頭回答的是
> 「**當初是誰付的**」。**那不是同一個問題。**

⇒ 同一把尺套在這裡：

```
這個欄位回答的是「**現在該去哪裡找**」    => **要改**（它是關聯）
這個欄位回答的是「**當時發生了什麼**」    => **不可以改**（它是歷史）
```

### 而 A 點名的難題（`case_updates` 的文字內容）**用這把尺會自己分開**

```
case_updates.quote_no（**欄位**）      現在該去哪裡找  => **改**
case_updates 的**文字內容**           當時某人寫下的字 => **不改**
```

🔑 ⇒ **不是「這張表算歷史還是算資料」，而是「這個欄位是關聯還是內容」。**
> **關聯一律改，人寫下的字一律不改。**

☠️ 而**混在一起問**的時候它看起來是兩難的 —— 因為同一張表兩種都有。

### ⚠️ 而「使用者搜舊單號搜不到」這個代價**仍然存在，要另外處置**

改欄位不改內容之後：
```
✅ 關聯不會斷
🔴 而使用者拿著舊單號（紙上、信裡、他記在腦子裡）**搜不到**
```

**建議**：`quotations` 保留一份**曾用單號**，搜尋時一併比對。

```
quotations.data_json["previousQuoteNos"] = ["MQ-202609-001", ...]
⇒ 每次改名 append，**不覆蓋**
```

**這個處置自己的副作用**（分開寫）：
```
⚠️ 搜尋要多比對一個欄位 —— 成本小，但它是 data_json 裡的陣列，
   若搜尋走 SQL LIKE 會變成掃描（要量，本規格沒量）
⚠️ 而它**不解決紙本**：外面那張舊紙上的號碼，系統裡的單已經是另一個號
   => 搜得到它、而搜到的那張與手上那張**內容可能已經不同**
   🔑 那是使用者裁「舊紙不算數」的直接後果，**不是缺陷**
      ⇒ 搜尋結果要標「**此單號已更新為 X**」，不要靜默導過去
```

📌 ⇒ **§2 整段要 A／使用者裁。** 我的建議是：判準用「關聯 vs 內容」，
搜尋用「曾用單號 ＋ 明著標示」。

## §3 交易邊界 —— **這一格不裁會直接變成更糟的狀態**

```
🔴 連動**必須**與 `UPDATE quotations SET quote_no=` 在**同一個交易**裡
☠️ 不同交易 ⇒ 中途失敗 = **報價單改名了而下游沒改**
   => 那比現在更糟：現在至少是「全部都指著舊號」，
      中途失敗會變成「**一半指舊號、一半指新號**」
```

```python
conn = get_db()
try:
    conn.execute("BEGIN IMMEDIATE")       # ⚠️ 明著開，不要靠隱式交易
    for table in _QN1_TABLES:             # §4 ①
        conn.execute('UPDATE "%s" SET quote_no=? WHERE quote_no=?' % table,
                     (new_no, old_no))
    _rewrite_embedded(conn, old_no, new_no)   # §4 ②
    conn.execute("UPDATE quotations SET quote_no=?, … WHERE quote_no=?", …)
    conn.commit()
except Exception:
    conn.rollback()
    raise
finally:
    conn.close()
```

⚠️ **順序**：先改下游、最後改 `quotations` ——
```
`quotations.quote_no` 是 UNIQUE（db.py:409）
=> 先改它的話，中途若失敗，新號已經佔住而下游還是舊號
```

⚠️ 而 `reject_quotation` 目前是 `conn.execute(...)` ＋ `conn.commit()`，
**沒有明著開交易** ⇒ 這一件會動到那一支的結構，B 要留意。

## §4 四個載體（**母體待 D**）

### ① 欄位：所有有 `quote_no` 欄位的表

```
母體取法  **對實際 DB 跑 `PRAGMA table_info`**，逐張表看有沒有 `quote_no`
          🔴 **不要 regex 掃 `db.py`** ——
             那條路已經產生過兩個不同的錯誤數字（`SPEC-QL25 §8b` 留著那一列）
清單      ［D 量測後貼入］
```

### ② JSON 內嵌的單號 —— **改欄位掃不到它**

```
🔑 `data_json` 裡的 `quoteNo` 是**字串不是欄位**
母體取法  對實際 DB 的每個 `*_json` 欄位，用**單號格式**（`MQ-\d{6}-\d{3}(-R\d+)?`）
          比對**值**，並印出它掛在哪個鍵路徑下
          ⚠️ 不要用鍵名比對 —— 鍵名可能是 quoteNo／quote_no／originalQuoteNo／…
          ⚠️ 也不要用 `LIKE '%quote%'` —— 太寬，會命中不含單號的欄位
清單      ［D 量測後貼入：(表, 欄位, 鍵路徑)］
```

⚠️ **已知一處**：`reject_quotation` 自己就寫 `d["quoteNo"] = new_no`（`:4459`）
⇒ 報價單自己那一筆**已經處理了**，`QN1` 要處理的是**其他表**的。

### ③ 檔名與目錄

```
問題  附件／PDF 是不是以 quote_no 命名或分目錄？
☠️ 是的話，改名之後**檔案還在而系統找不到** —— 〈降級之後它還是會動〉
母體取法  讀 `save_document_files()` 的 `subfolder`／`doc_no` 實際傳什麼，
          並**列出 uploads/ 底下的實際目錄名**對照
          🔑 兩邊都要看：程式碼說的與磁碟上的可能已經不同
清單      ［D 量測後貼入］
```

⚠️ **已知一處反例**：`vouchers.py:955` 附近的註解逐字寫著
「路徑的 `doc_no` 用 `str(voucher_id)` ⇒ **不含單號**（單號會升版）」
🔑 ⇒ **傳票那邊已經想過這件事並避開了** —— 那是一個**已經做對的先例**，
   ⇒ ③ 的修法優先考慮「**改成不含單號**」而不是「改名時一起搬檔案」。
☠️ 搬檔案的失敗模式是**檔案搬了一半**，而它不在任何交易裡。

### ④ 稽核軌跡 —— **不可以改**

```
trail ／ audit_log ／ *_edit_log ／ statusLog
=> 它們回答「**當時發生了什麼**」 => 一律**排除**
🔑 改了就等於竄改歷史
```

⚠️ **排除清單要寫理由，而且要能被檢查**：
```
✅ 每一筆排除要寫「它回答的是哪一個問題」
❌ 不可以寫「這張表看起來不用改」
⚙️ 反向控制：排除清單的長度**不可以自己變長**
   ☠️ 否則可以靠把全部表寫進排除清單讓守門變綠
```

## §5 守門 —— **加總型**

> 🔑 唯一會**自己翻臉**的檢查是加總。其餘每一項都只會說「通過」。

```
✅ 掃 DB schema 找出**每一張**有 `quote_no` 欄位的表，
   斷言 **每一張都在「連動清單 ∪ 排除清單」裡**
   => 將來新增一張表時，它會**自己翻臉**
☠️ **不要釘一個數字**（例如「15 張」）——
   新增表那天最省力的反應是把數字加一，
   而**沒有人會去看那一張表該連動還是該排除**
   📌 守門從「檢查」退化成「記帳」，而那一步不留痕跡

✅ 同理 ②：掃每個 `*_json` 欄位的**值**，斷言不存在「指向已不存在單號」的內嵌
   ⚙️ 正對照 造一張退回過的單，斷言下游全部指到新號
   ⚙️ 負對照 稽核軌跡裡的舊號**必須還在**
      🔑 少了這個負對照，「全部改掉」也會全綠 —— **而那正是竄改歷史**
```

## §6 驗收（`AC1`）

```
① 後端  退回一張有下游資料的單 -> 所有連動表指到新號、排除表維持舊號
        ⚠️ 而「有下游資料」要**實際造出來**，不可以只退一張空單
② 前端  無異動（除非 §2 的「曾用單號」搜尋落地）
③ 頁面  ⓐ 退回前記下舊號 -> 退回 -> 用**新號**開得到案件的全部資料
        ⓑ 用**舊號**搜尋 -> 依 §2 裁定：搜得到且標「已更新為 X」，或明確查無
        ⓒ 稽核紀錄裡**還看得到舊號**
        🔑 ⓒ 是負對照 —— 沒有它就分不出「連動做對了」與「把歷史也改掉了」
```
