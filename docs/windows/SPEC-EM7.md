## §1 判準

> ### 一筆資料被放棄了，而**沒有任何地方說它被放棄**。

```
for row in rows:
    try:
        …
    except Exception:
        continue          # <= 這一筆沒了，而迴圈結束時沒有人知道少了幾筆
```

### 🔑 它與「有沒有 `continue`」不是同一個問題

```
✅ 合法：多路徑輪詢（讀不到就試下一個）
✅ 合法：這一筆本來就不該處理（過濾）
🔴 違規：這一筆**應該**被處理，而它被丟掉了，**且沒有計數、沒有 log**
```

### ☠️ 最貴的形狀：**成功的會寫 log，失敗的不會**

`archive.py` 的 `_prune_cloud_backups`：
```
刪掉一個過期備份   => 寫 log
名字不合法而跳過   => **不寫**
=> 那個目錄**永遠不進保留政策**，而 log 上看起來一切正常
```
🔑 〈防護的副作用落在盲側〉的教科書形狀：
**你看得到它做了什麼，看不到它沒做什麼。**
