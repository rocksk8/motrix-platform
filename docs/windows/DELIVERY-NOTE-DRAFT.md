# 🔵 你回報的「每次進入地圖都要重新定位」——查出來了

你說：**「每次都還有 1xx 個地址這次來不及定位，上次剩 60 個這是回到 103」**

## 成因

```
地圖要用到的地址   195 個
已經定位好的      142 個
定不到位的         53 個
```

**而定不到位的那 53 個，系統以前是「查不到就什麼都不記」** ——
```
這次查 → 查不到 → 不記 → 下次它又排進待辦 → 又查一次 → 又查不到
⇒ **永遠不會變少**
```
而標案雷達每天帶進新的機關名稱 ⇒ **60 → 103 就是這樣長出來的。**

## 這一版改了什麼

**查不到的地址現在會被記下來，一段時間內不再重試。**
⇒ 每次開地圖不會再把時間花在那些查不到的上面，**已經定位好的那 142 個會直接顯示**。

## ⚠️ 而那 53 個**仍然定不到位**，這一版沒有改變這件事

```
那 53 個裡      有縣市的 21 個 ／ 有區鄉鎮的 7 個 ／ 有路街的 9 個
                **32 個連縣市都沒有**（多半是標案的機關名稱）
```
**免費的定位服務查不到它們。** 這一版做的是「不再無謂重試」，不是「把它們定出來」。

### ⇒ 畫面上的訊息因此分成兩種，請注意差別

```
「這次來不及定位」   時間不夠 ⇒ **下次會再試**，你什麼都不用做
「查不到這個地址」   已經試過了 ⇒ 🔴 **要你去改那一筆資料的地址**
```

⚠️ **「已經試過了」會被記住多久**：**到伺服器下次重啟為止**（最長七天）。
📌 **你不需要做任何「清除快取」的動作** —— 下次部署或重開機就會自動清掉。
（而系統裡也沒有那個按鈕，因為不需要。）
📌 **以前這兩種都顯示同一句話**，所以看起來像「系統一直在忙」，
而其中一部分其實是在等你。

# 附近產業探索 —— **看起來做得到，而要先花很小的一筆確認它是真的**

> ⚠️ 這一節我們改寫過三次。前兩版的結論（「撞到 Google 條款，做不了」）**是錯的**，
> 因為我們一開始只想到用 Google。下面是查完之後的版本。
>
> 🔴 **而「做得到」這三個字我們也還沒有證據**：下面整條路都建立在**政府的開發文件**上，
> **我們一次都沒有真的打過那個 API**（要先完成申請才能打）。
> 而 11 支產業別 API 裡有 10 支標著「(測試)」，**製造業與專業科技業都在那 10 支裡**。

### 做得到的路

```
1  從經濟部的開放資料，把整個產業的公司一次抓下來    名稱 ✅ 統編 ✅ 地址 ✅
   「加工業」對到 C 製造業 與 E 營造及工程業
   「科技業」對到 I 專業、科學及技術服務業
2  存進我們自己的資料庫                            ✅ 開放資料，沒有條款問題
3  把地址轉成座標                                  🔴 **這一步要錢，見下**
4  「附近有哪些加工業」就變成我們自己資料庫的一次查詢   ✅ 之後完全不用再對外
```

🔑 **這條路完全不碰 Google Places**，所以前兩版講的那些限制（不能存店名地址、
不能畫在我們的地圖上）**通通不存在**。而且產業分類用的是**政府的官方代碼**，
比 Google 自己那套「商店／餐廳」的粗分類準得多。

### 🔴 而它卡在第 3 步：地址轉座標要錢

我們實測過：**免費的定位服務對台灣的門牌號碼完全查不到**
（試了 8 種寫法，連台中市政府、台北市政府的完整地址都查不到，
只有「某某路」「某某區」這種層級查得到）。

⇒ 用免費的做，**幾萬筆公司會全部疊在同一個行政區中心點上**，
**「附近」這個功能在精度上直接失效**。

⇒ **所以要做這條路，必須付費把地址轉成座標。**

### ⭐ 但不用付全台灣的錢

政府回傳的「公司地址」是一段**文字**，所以可以**先用字串把縣市篩掉**
（例如只留地址含「台中市」的那些）——**這一步零成本、不用打任何 API。**

```
不需要   把全台灣幾十萬筆公司都轉成座標
只需要   轉你所在的那個縣市，幾千到幾萬筆
費用 ＝ 那個數字 × 每筆的定位費用，而且是**一次性的**
⚠️ 而**抓資料的次數不會因為篩縣市而減少** —— 政府的 API 不接受地址篩選，
   整個產業還是要整包拉下來才能在本地篩。那是兩種不同的成本。
座標轉好之後就是我們自己的了，永久保存沒有問題
之後每次查「附近」都是本機運算，不再產生任何費用
```


### ⭐ 順序很重要：**便宜的那一步先做**

```
第一步  申請 IP 登記 ＋ 打一次 API       **免費**
        答的是：它還活著嗎？回傳的欄位真的長那樣嗎？那個產業在你的縣市有幾筆？
第二步  決定要不要付地址轉座標的錢        要錢
        而且**要等第一步的筆數才算得出來**
```

🔑 **不要在第一步之前決定第二步。**
而第一步的產出**正好就是估價需要的那個數字**。

### ⭐ 所以要你決定的是一個數字

**做完第一步之後**，要決定的是：願不願意為「一次性把某幾個產業的公司地址轉成座標」付這筆錢。

⚠️ 我們現在**算不出那個數字**，因為不知道每個產業有幾筆公司 —— 那正是第一步要答的。

### ⚠️ 三件你要先知道的代價

```
① 要申請       那個 API 要填一份使用告知書寄給經濟部，**而且要登記固定的對外 IP**
               ⇒ 這件事每一個用這套系統的公司都要自己做一次，而 IP 換了要重登記
② 拿不到全部   名稱 ✅ 統編 ✅ 地址 ✅ ／ **官網 ❌ 聯繫方式 ❌**
               那兩個欄位在政府資料裡就是沒有
③ 穩定性       11 支產業別 API 裡，**10 支標著「(測試)」**
               只有「零售、批發及餐飲業」那一支是正式版
               ⇒ 測試版隨時可能被撤掉，而我們不會收到通知
```

                      客戶／供應商／標案機關已經在圖上了
                      零申請、零費用、零風險
