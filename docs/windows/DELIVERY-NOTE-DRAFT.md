## ① 回滾會把**資料**一起還原到部署前那一刻

> **部署之後輸入的任何東西都會不見。**

# 🔑 部署完成後，明天可以做一個檢查

我們發現一個免費的方法可以事後確認「**服務到底有沒有真的重啟**」——
那一步在 `DEPLOY.md` 裡是 🔴🔴 的，而它原本只能看畫面確認。

方法：比較兩份每日備份裡 `module_versions` 的 `sqlite_sequence`。

```
Δ ≈ 371（或其倍數）  ⇒ 服務真的重啟了，新程式碼生效了
Δ = 0                ⇒ 🔴 部署了但服務沒重啟 —— **新程式碼從來沒跑起來**
```

實測基線（2026-09-15~09-22 連續八天）：`+1769`／`+716`／然後連續五天 `+0`。**沒有重啟時就是乾淨的 0，不需要容忍區間。**

⚠️ **而它答的是「到昨天午夜為止」**——每日備份是 00:00 取的。部署當天去查會看到 `0` 而誤判。

> 📌 **順帶一提**：你 2026-09-22 10:26:58 那次部署，我們手上到 09-22 00:00 的資料還看不到。
> **09-23 那份備份就是答案**。如果那天的 Δ 仍然是 0，代表那一包到現在都沒有真的跑起來。
