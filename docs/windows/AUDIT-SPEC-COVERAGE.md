   grep -w "VR6"     => **0 命中**

> ### ☠️ **它回 0 命中而且結束碼是 0** —— 看起來就像「真的沒有」。

   ☠️ 我原本完全可以只相信 grep（它是我先跑的那一個）
```

> ### ⚠️ ⇒ **這個 repo 的文件與註解幾乎全是中文**
> ### ⇒ `grep` 的 `\b`／`-w` 在這裡**一律不可信**。
