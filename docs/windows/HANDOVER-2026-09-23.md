## 0b. 🔴🔴 **四件出貨阻擋 —— 這是這一段最重要的發現**

> 全部在「把 ERP 變成可販售的產品」這條線上，而**四件都不是有人去找才找到的**：
> 都是在做別的事情的路上撞到的。🔑 **那本身就是一個訊號。**

### ① `IA1`｜出廠管理員的身分寫死在產品碼裡
```python
# backend/helpers/startup.py  init_default_admin()   ← **每次啟動都跑，不是 migration**
INSERT INTO users (...) VALUES ('jeff', '黃玉龍', 'superadmin', 'jeff@miactw.com', ...)
```
🔴 而**不只是預設值** —— `'jeff'` 寫在**存取控制邏輯**裡：
```
routers/auth.py:1548  delete_user()        username=='jeff' => 400「不可刪除超級管理員帳號」
routers/auth.py:1582  toggle_user_active() username=='jeff' => 400「不可停用」
frontend/pages/users.html ×5                配合隱藏刪除/停用按鈕
```
> ### ☠️ **客戶的系統裡會有一個永遠刪不掉、停不掉、名字叫 `jeff` 的帳號。**
```
⚠️ 客戶改成自己的名字之後**不會**被改回去（兩句 UPDATE 都有 WHERE 守衛）
   而**把顯示名或 email 清空的話會被填回「黃玉龍」／jeff@miactw.com**
✅ 安裝流程本身是想過的（隨機臨時密碼、憑證檔、must_change_password=1）=> 只要改身分三個值
```

### ② `IA2`｜一個客戶不知道的 superadmin，密碼是一個公開數字
```python
# backend/helpers/startup.py  init_demo_account()   ← main.py:528 **無條件呼叫，沒有開關**
VALUES ('demo', ?, '展示帳號', 'superadmin', ?, 1, ?, 0)   # must_change_password = 0
_hash_pw("60575481")                                       # 密碼 = **公司統一編號**
logger.info("已建立展示帳號（demo），密碼 60575481")         # 🔴 明文寫進 logs/server.log
```
```
⚙️ 三件都查過，三件都空：① 有開關嗎 => 沒有 ② 登入頁看得到嗎 => 看不到 ③ 授權底座處理了嗎 => 沒有
🔑 而那個密碼**印在客戶自己匯出的 PDF 頁尾上**
```
> ### ✅ **資料隔離是真的**（demo 登入後路由到隔離 DB）⇒ ❌ 不是「客戶資料會外洩」
> ### ✅ 是「**客戶的系統裡有一個他不知道的 superadmin，而它的密碼是一個公開數字**」
> ### 🔑 **真正的問題不是它能做什麼，是它不該在那裡。**

### ③ `WL1`｜兩份報表印我們的公司名與統編，而它們**完全不讀 `company_profile`**
```
backend/routers/reports.py           => 營運報表 Excel／PDF、銷項發票清單
backend/network_plan_export.py       => 網路架構規劃書 Excel／PDF
⚙️ grep -c company_profile 兩支都是 **0**（實跑過）
```
> ### ☠️ **客戶不管怎麼改公司設定，這兩份報表永遠印允碩的公司名與統編。**
⚠️ 而它**不是**「尚未設定公司抬頭」那個 bug（`JV9`，那是有設定而讀不到）——
  這一支是**根本沒有去讀**。
⚠️ 而**只換那兩個常數不夠**：`network_plan_export.py:380/:481` 把公司名／email／電話／統編
  **直接內嵌在 f-string 裡**。

### ④ `JV27`｜一支重複實作讓一個安全設計**不可達**
```
routers/vouchers.py:153 _appr_of()  <= 獨立於 helpers/voucher.py _chain_tiers() 的第二份解析
```
