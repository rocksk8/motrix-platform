```
每一條都已經**有一個決定**，而系統照那個決定在做。
=> 您只要看**不同意的那幾條**，其餘不必回。

   ✅ 您裁：維持   => 我們原本的決定您同意了，**而那兩條已經做完**
   🔄 您裁：改成…  => 您換了一個做法，⏸ **而它已暫停**（見下一段）

每一條三行：
   ❓ 問題        一句話
   ✅ 目前的決定  我們裁的，而系統照它在做
   ⚠️ 若您要改    改了之後會動到什麼
```
