---

## §1 判準

> ### 同一句權限訊息裡，一半是**角色**、一半是**模組** ——
> ### 而使用者在畫面上**只找得到其中一半**。

```
「僅管理員、**出納**或**財務**可查閱」
  管理員  => 角色（users.html 的 roleLabels，**客戶可改**）
  出納    => **模組權限**（user_has_module(user, "cashier")）
  財務    => **模組權限**（user_has_module(user, "finance")）
```

☠️ ⇒ `EM2` 把角色名改成動態之後，這幾句會變成
**「一半動態、一半寫死」—— 看起來比現在更一致，其實沒有。**

---

## §2 🔴 相依關係：**`EM2` 先，這一件後**

```
EM2 未落地 => 這 6 句裡的「管理員」還是寫死的
           => 改模組那一半沒有意義（兩半都寫死，至少是一致的）
EM2 落地後 => 角色那一半跟著設定走、模組那一半不動
           => **這時候才會出現不一致**
```
📌 ⇒ 本規格排在 `EM2` 之後。**現在寫是為了讓 `EM2` 落地時不會忘記它。**

## §6b ✅ 拆 `label` ＋ `hint`（A 2026-09-23 裁定）

### 🔴 母體是 **2** 筆，不是 21

```

```

> ### 🔑 拆掉破折號 ⇒ **兩個不同的權限會變成同一個名字**（都叫「網路架構規劃書」）。

📌 ⇒ 又一次〈先問「這個母體裡有幾種東西」〉：
