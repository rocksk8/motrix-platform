## §3 怎麼產、怎麼合併

```
產本體   HTML -> **Edge Headless --print-to-pdf**（helpers/startup.py::run_edge_pdf）
         ⚠️ 那一支**吞掉逾時不丟例外**（docstring 逐字），靠呼叫端緊接的
            「tmp_pdf 沒產出或 0 byte 就 raise」那道檢查報錯
         ⇒ **本項必須照抄那道檢查**，十六個既有呼叫端都有它
         ⚠️ 併發受 EDGE_PDF_SEMAPHORE 限制、逾時 120 秒（可用 MOTRIX_EDGE_PDF_TIMEOUT 調）
合併     **pypdf**（掛在本項，見 §4）
```

### 🔴 圖片附件**不需要** `pypdf`，也**可能不需要** `Pillow`

```
圖片 => 直接 <img> 進同一份 HTML（每張一頁，CSS page-break）
        ⇒ Edge 一次印出 ⇒ **零新增套件、零額外 Edge 執行**
PDF  => Edge 做不到 ⇒ pypdf 合併
```
⇒ **建議做法：一次 Edge 產出「本體＋所有圖片附件」，再用 `pypdf` 把 PDF 附件接上去。**
這樣 Edge 只跑一次（它是有 semaphore 的稀缺資源）。

⚠️ **待查（我沒驗）**：手機照片的 EXIF 旋轉。現代瀏覽器預設
`image-orientation: from-image`，**而我沒有在 Edge headless 上實測過**
⇒ 若實測發現躺平，才需要 `Pillow`（已在 `requirements.txt`，零新增）。
**不要因為「可能需要」就先加程式碼。**

## §5 🔴 附件的實體檔遺失時怎麼辦（A-2 判定）

`JV3` 的「帶入」遇到這種情況是**整批拒絕 400**。
**而那個類比在這裡不成立**，理由是動作的性質不同：

```
JV3 帶入   **寫入** —— 它在資料庫裡建立一個主張：「這張傳票有這份憑證」
           部分成功 => **留下一句謊** => 所以整批拒絕是對的
JV5 匯出   **唯讀** —— 它不改變任何主張，只是把既有的主張印出來
```

**⇒ 判定：匯出不拒絕，而是把缺口印在輸出裡。**

```
❌ 整批拒絕     => 一份**法定要保存的憑證**因為一個附件而印不出來
                   （《商業會計法》§38：憑證 ≥5 年）⇒ 代價不成比例
❌ 靜默略過     => 使用者拿到一份**看起來完整**的 PDF ⇒ 那比印不出來更糟
✅ **印出來**   => 在合併後的 PDF 最後加一頁「未能併入的附件」，
                   逐筆列出 filename／uploaded_at／來源，並寫明「原始檔案已遺失」
```

🔑 **一個唯讀動作拒絕執行，擋住的是使用者；靜默略過，騙的是使用者。
第三條路是把缺口輸出出來。**
📌 而這正是 A 轉述的那句的另一半：
> 清單那一層**說實話**，寫入那一層**擋住錯誤的結果**。
匯出屬於「說實話」那一層。

⚠️ **而它必須同時反映在回應上**，不能只印在紙上：
```
回應 header 或 JSON 要帶「N 個附件未併入」
⇒ 否則呼叫端（前端／自動化）無法分辨「完整」與「缺了東西」
```

### ⚠️ 匯出的 PDF 是**快照**，要自己說出它是什麼時候的

附件可以在匯出之後再新增 ⇒ 兩份同一張傳票的 PDF 內容可以不同。
⇒ 頁尾印 **匯出時間 ＋ 併入的附件筆數**。
☠️ 沒有這一行的話，兩份不同的 PDF 拿在手上**分不出哪一份比較新**。

## §7 驗收（`AC1`：後端＋前端＋頁面三者皆備）

```
後端 ① 只印本體：回 200、Content-Type 是 application/pdf、**位元組數 > 0**
     ② 附件全是圖片：一次 Edge 產出，總頁數 == 1 + 圖片數
     ③ 附件含 PDF：總頁數 == 1 + 圖片數 + 各 PDF 的頁數合計
     ④ **一個附件的實體檔被刪掉** -> **仍然回 200**，且
        (a) 輸出多一頁「未能併入的附件」且列出那個 filename
        (b) 回應明著帶出「1 個附件未併入」
        ⇒ **這一題是 §5 的全部**，它紅而其他全綠 = 沒做到
     ⑤ 已作廢的傳票也印得出來（`get_voucher` 讀 `vouchers_all` 不是 VIEW）
     ⑥ 未過帳的傳票：科目名稱取**現值**；已過帳：取 snapshot
        ⚠️ 觀測方式：過帳後**改掉科目名稱**，再匯出，紙上必須是舊名字
     ⑦ 權限：無 cashier／finance 模組 -> 403（**不是 200 空檔**）
     ⑧ 先斷言 status_code in (200, 400, 403)，再看內容
        —— 未實作端點在這個 repo 有三種臉：404／405／422（`§166`）
前端 ⑨ 傳票頁有「匯出 PDF」與「匯出（含附件）」兩個會送出的動作
頁面 ⑩ 未併入附件時，畫面也要說（不能只有 PDF 裡有）
```

⚠️ ②③ 要**數頁數**，不要只驗「檔案非空」——
☠️ 合併失敗最可能的樣子是「只有本體那一頁」，而它是一份完全正常的 PDF。
