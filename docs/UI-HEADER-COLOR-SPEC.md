# 介面規格：選單 · 頁頭 · 語意色票 · 對比與字級（2026-11-11）

來源：hichan-9 〈介面「新手好上手」優化提案〉B1／B2／B3／B6／D1／D2／D3。新頁、改版頁照這份做；舊頁隨改版逐步套用。

## 1. 選單（B1／B2／B3）

選單**只有一份宣告**：`backend/core/menu_l1.json`（群組、L1 頁面）＋各模組 `module.json` 的 `pages[].menu`。畫面（`static/sidebar.js`）不寫死任何項目。

| 群組鍵 | 顯示名稱 | 內容 |
|---|---|---|
| `business` | 客戶與業務 | 業務開發、標案雷達、客戶管理、報價單、地圖 |
| `case` | 案件 | 案件管理、案件執行看板 |
| `supply` | 採購與庫存 | 供應商、承攬商、料號、庫存、採購、設備登載、保固追蹤、網路架構規劃書 |
| `finance` | 財務會計 | 日常（出納、傳票）／月結（總帳作業、會計期間與結帳、獎金分潤）／設定（會計科目、收款帳號） |
| `analysis` | 報表 | 收成**單一**一級入口「報表」→ 報表中心（`reports-hub.html`） |
| `payroll` / `mywork` / `system` | 勞務管理／我的工作／系統 | 未動 |

選單項新增兩個**選填**欄位（`core.menu.ITEM_KEYS`）：
- `section`：同一群組內的小標題。下拉面板每個連續的 section 一欄、欄頂印標題；沒有任何項目帶 `section` 的群組與原本完全相同。**同一 section 的 `order` 要相鄰**。報表群組的 `section` 同時是報表中心的頁籤名（「設定」不佔頁籤，收成頁頭右側齒輪）。
- `desc`：一句話「這項回答什麼問題」，用 `；` 分隔多個問題。報表中心卡片用它。

**報表中心**：群組裡有 `hub: true` 的項目（`reports-hub.html`）⇒ 導覽列把整個群組收成一個連結（機制同「系統」）。報表中心的卡片來自 `MotrixMenu.groupItems('analysis')`（宣告 ＋ 這位使用者的權限與角色版面），頁面不寫死有哪些報表。新增報表 ＝ 在該模組 `module.json` 宣告一個 `analysis` 群組的選單項（帶 `section`、`desc`）。子頁（營運報表／財務報表／帳簿報表／報表設定）頂端自動出現「← 報表」連回報表中心。

## 2. 頁頭規格（B6）

```html
<div class="pg">
  <div class="pg__l">
    <nav class="pg__crumb" data-crumb-auto aria-label="目前位置"><span>客戶管理</span></nav>
    <h1 class="pg__t">客戶管理</h1>
    <p class="pg__s">一句話說明這頁做什麼</p>
  </div>
  <div class="pg__a"><!-- 右側主要動作（一個 .btn-primary） --></div>
</div>
```

- 麵包屑（一級 › 頁面）取代舊的 `.pg__eyebrow`。一級名稱**不要手寫**：標 `data-crumb-auto`，`sidebar.js` 依選單宣告補上「這頁屬於哪個群組」（hub 群組的名稱連回 hub）。群組改名、頁面搬組都只改宣告。
- 單一 `<h1 class="pg__t">`；說明一句（`.pg__s`）；主要動作放右側 `.pg__a`，一頁只有一個實心主按鈕。
- 有 `.pg__crumb` 的頁面，頂部黑列不再重複印頁名（`body:has(.pg__crumb) .topbar__title` 隱藏）。
- 已套用：報表中心（新）、客戶管理、供應商、承攬商、料號、庫存、採購、設備登載、保固追蹤、網路架構規劃書（群組有搬動或改名者）。其餘頁面保留 `.pg__eyebrow`，隨改版逐步換。

## 3. 語意色票（D2）

一種顏色只回答一個問題：

| 意義 | token | 用在 |
|---|---|---|
| 主要動作 | `--accent` 品牌紅 | 實心主按鈕、標題記號條 |
| 危險／錯誤 | `--danger` | 錯誤訊息、刪除、驗證失敗。**不拿來當說明框** |
| 警告 | `--warning` 琥珀 | 待審核、快到期、需留意 |
| 成功 | `--success` 綠 | 已完成、已確認 |
| 資訊／說明 | `--info` 藍（`--info-light`、`--info-border`） | 說明框、提示、一般通知、鈴鐺裡的待簽核提醒 |
| 內部／機密 | `--internal` 紫（`--internal-light`、`--internal-border`） | 成本、毛利、薪資等不可對客戶輸出的內容 |

- 說明框一律 `<div class="callout">`（藍）；`.callout--warn`／`--danger`／`--success`／`--internal` 為變體。
- 已把「拿紅框當說明」的四頁改成藍色資訊框：公司資料設定、簽核設定、通知設定、Google 行事曆設定（`.ns-desc`／`.as-desc`）。
- `--danger` 的值**不動**：已有多支測試釘住 `rgb(185,28,28)`；與品牌紅 `#C8102E` 的區分靠上表的「用途規則」。
- 文字色不要寫死十六進位：`#DC2626`→`var(--danger)`、`#16A34A`→`var(--success)`、`#D97706`→`var(--warning)`、`#6B7280`／`#64748B`→`var(--text-secondary)`、`#9CA3AF`→`var(--text-dim)`（本次已在前端全數替換，報價單表單與結算單除外，見下）。

## 4. 對比與字級（D3）

- 次要文字對**頁面底色 `#F5F4F0`**（不是純白）至少 4.5:1：`--text-secondary #595959`（6.4:1）、`--text-dim #666666`（5.2:1；對 `#F0EEE9` 4.95、對 `#FBE9EC` 4.9）。深色區塊的次要文字用 `--text-on-dark-dim #A3A3A3`（對 `#0A0A0A` 7.85、對 `#2A2A2A` 5.69）。
- 最小字級 12px：前端 CSS／行內樣式裡所有 `font-size:` 小於 12px 的宣告已統一成 12px（1,683 處，97 檔）。`@media print` 區塊不動。
- 掃描方法：Playwright 走訪 33 頁，逐一文字節點取實際前景色與疊合後背景色算比值（大字 ≥ 24px 或 ≥ 18.66px 粗體用 3:1），並比對 1440／1024 寬的橫向捲動與被裁切的文字數量；改前 382 處不達標 → 改後 0（報價單表單與結算單除外）。
- **未處理（另案）**：`quotation-form.html`（FORM_VERSION 帳與 C 項改版進行中，且內含列印預覽版面）與 `settlement.html`（列印版面）的小於 12px 字級與少數低對比色，以及報價單內部成本面板（黑底）的灰字。
