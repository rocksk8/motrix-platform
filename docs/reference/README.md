## 商業會計項目表（112 年度及以後適用版本）

```
檔案   商業會計項目表-112年度及以後適用版本.pdf   1,578,890 bytes / 42 頁
來源   https://gcis.nat.gov.tw/F/t70492_p   （經濟部商業司）
依據   商業會計法第 27 條
sha256 872f827ce18157b9b8e26a979c7bb47b7952ddee68fd850a363e869d419e2d34
取得   2026-09-22 22:23（A-2）
```

🔴 **為什麼要存進 repo（而不是「需要時再下載」）**

```
它是 v94（載入標準會計項目）那支 migration 的**唯一輸入**
⇒ 沒有它，那份靜態資料**重新產生不出來**，也**驗證不了**
⚠️ 而它原本只存在於某個 session 的暫存目錄裡 —— session 一結束就沒了
```
📌 〈腳本活在 session 裡就等於不存在〉——**原始資料也一樣。**

🔴 **`.sha256` 是這裡的重點，不是附註**

```
三個一起釘，才是一道能重跑的守門：
  **解析器 ＋ 輸入指紋 ＋ 輸出筆數**
```
☠️ 少了指紋：哪天有人更新成新年度版，**解析結果會變，而沒有東西會說它變了**。

⚠️ **未查**：112 年版之後有沒有更新版（**未查公告**）。
⇒ 這份只能保證「我們讀的就是這一份」，**不能保證「這是現行最新版」**。
🔑 抓錯版本的代價是「**一份看起來完全正常的錯資料**」，而它會一路走進 `v94`。

## 版本查核（2026-09-22 23:4x，A）

### ✅ 同一個網址仍然供應同一份檔（**強證據**）

```
重新抓 https://gcis.nat.gov.tw/F/t70492_p
sha256 **872f827c…**（與 repo 裡這一份**逐字相同**）
size   1,578,890（相同）
```
⇒ **那個官方網址沒有換檔。**

### ⚠️ 「有沒有更新版」——**沒有找到，而這是弱證據**

```
查的範圍  網域限定搜尋（gcis.nat.gov.tw／moea.gov.tw／law.moj.gov.tw）
          ＋ 上面那次指紋比對
結果      **沒有出現比「112年度及以後適用版本」更新的版本**
```
🔴 **而「搜尋沒出現」不等於「不存在」** —— 這是否定句，它比肯定句弱。
📌 ➕ 一個支持它的旁證（仍然不是證明）：
**標題寫的是「112 年度**及以後**適用版本」** ⇒ 它本來就設計成沿用到被取代為止。

### 🔑 ⇒ 把一次性的問題變成可重跑的檢查

```bash
# 重抓並比對指紋；不同 ⇒ 官方換檔了，解析結果要重驗
curl -sL https://gcis.nat.gov.tw/F/t70492_p -o /tmp/x.pdf && sha256sum /tmp/x.pdf
# 期望：872f827ce18157b9b8e26a979c7bb47b7952ddee68fd850a363e869d419e2d34
```
⚠️ **這道檢查答的是「那個網址有沒有換檔」，不是「有沒有新版本發布在別處」。**
⇒ 後者**仍然沒有自動化的答案**。
