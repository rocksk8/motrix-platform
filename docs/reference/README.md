🔴 **為什麼要存進 repo（而不是「需要時再下載」）**

```
它是 v94（載入標準會計項目）那支 migration 的**唯一輸入**
⇒ 沒有它，那份靜態資料**重新產生不出來**，也**驗證不了**
⚠️ 而它原本只存在於某個 session 的暫存目錄裡 —— session 一結束就沒了
```
📌 〈腳本活在 session 裡就等於不存在〉——**原始資料也一樣。**

🔴 **`.sha256` 是這裡的重點，不是附註**

```
三個一起釘，才是一道能重跑的守門：
  **解析器 ＋ 輸入指紋 ＋ 輸出筆數**
```
☠️ 少了指紋：哪天有人更新成新年度版，**解析結果會變，而沒有東西會說它變了**。

⚠️ **未查**：112 年版之後有沒有更新版（**未查公告**）。
