### 內部成本分析（右側區塊）

**直接利潤彙整 DIRECT PROFIT：**
- 銷售總額 → 商品成本(未稅) → 進項稅金5% → 直接毛利 → 直接毛利率

**間接成本分攤 INDIRECT COSTS：**
- 運輸物流（出貨/報關/保險）
- 安裝施工（技師工時）
- 差旅費（交通/住宿/餐）
- 管銷分攤（銷售額 × 10%）
- 保固預估（未來維修預提）
- 其他

**損益總結 NET PROFIT SUMMARY：**
```
銷售收入(扣除營業稅)
−  直接成本(未稅)
−  進項稅金(5%)
＝  直接毛利
−  間接成本
＝  稅前淨利
×  假設所得稅率（預設0，可調整）
−  所得稅
＝  稅後淨利 Net Profit
   淨利率 Net Margin（目標 ≥ 12%）
```

## 三、核心定價公式（必須完整複製）

```python
import math

def calculate_unit_price(cost: float, margin: float) -> float:
    """
    cost   : 成本單價（未稅）
    margin : 目標毛利率（如 0.3 = 30%）
    回傳   : 對外報價單價（未稅）
    """
    base = math.ceil(cost * 1.05 / (1 - margin) / 5) * 5  # CEILING(..., 5)
    remainder = base % 100
    if remainder > 50:
        return math.ceil(base / 100) * 100          # 無條件進至百位
    elif remainder > 0:
        return math.ceil(base / 100) * 100 - 50     # 進至 x50
    else:
        return base                                  # 已是整百
```

## 九、草稿自動儲存機制（已確認）

**所有有填寫欄位的文件類型，一律支援草稿區，防止瀏覽器跳轉後資料遺失。**

涵蓋的文件類型：
- 報價單（含所有明細行、條件文字）
- 折讓申請
- 管銷分攤率調整申請
- 採購單
- 銷售訂單
- （未來）客戶資料新增/編輯

### 技術實作方式

| 層級 | 機制 |
|------|------|
| 前端即時 | `localStorage` — 每 30 秒或欄位 `blur` 時自動存瀏覽器本地 |
| 後端持久 | 資料庫 `status='草稿'` — 使用者主動「儲存草稿」或定時 auto-save（60秒）POST 到後端 |
| 離開提示 | 未儲存修改時離開頁面，顯示「您有未儲存的變更，確定離開？」 |
| 草稿清單 | 儀表板顯示「我的草稿」列表，點擊可繼續編輯 |

### 草稿狀態規則
- 草稿只對「建立者」可見，管理者在審核清單才能看到
- 草稿不計入任何統計報表
- 草稿 **90 天無修改** 自動提醒使用者是否刪除（不自動刪）

## 十一、設備管理模組（Device Lifecycle Management）

### 功能架構

```
設備管理
  ├── 料號主檔（品項庫）
  ├── 設備入庫登載（個體序號/MAC）
  ├── 設備出貨綁定（連結客戶 + 銷售訂單）
  ├── 設備履歷查詢（輸入SN/MAC即看全生命週期）
  ├── 保固到期追蹤（自動提醒）
  ├── RMA 維修管理
  └── 客戶設備清冊（每個客戶有什麼設備、哪些案件）
```

### 設備入庫登載操作流程

1. **採購入庫時**：
   - 選擇採購單（PO） → 選擇品項
   - 逐台輸入 S/N + MAC（或 Excel 批次匯入）
   - 系統自動計算保固到期日（採購日 + 保固月數）
   - 狀態設為「庫存中」

2. **出貨時**：
   - 建立銷售訂單 → 選擇要出貨的設備個體（by S/N）
   - 填入安裝位置（選填）
   - 確認出貨後 → 狀態自動更新為「已出貨」，綁定客戶

3. **維修時**：
   - 搜尋設備（by MAC/SN） → 開立 RMA 單
   - 記錄故障描述 → 送修廠商 → 追蹤進度
   - 維修回收後 → 狀態恢復「部署中」或「庫存中」

## 十三、使用者與權限設計（已確認）

### 角色定義

| 角色 | 英文代碼 | 說明 |
|------|----------|------|
| 業務人員 | `sales` | 建立/編輯報價單、填寫明細、送出審核 |
| 管理者 | `manager` | 審核特殊報價、系統設定、查看成本分析 |

### 報價人資訊自動帶入
- 報價人姓名、電話、Email → 由**登入帳號資料**自動填入
- 使用者主檔需包含：姓名、職稱、電話、Email

### 審核觸發條件（任一成立即需管理者核准）

| 條件 | 說明 |
|------|------|
| 有效期限 > 30 天 | 超過標準有效期需管理者核准 |
| 任一品項目標毛利率 < 30% | 低利率報價需管理者審核 |
| 折讓金額 > 0 | 啟用折讓本身即為特殊操作（見下方） |
| 管銷分攤率 ≠ 10% | 調整固定比例需申請（見下方） |

### 審核流程

```
業務填寫報價單
      │
      ├─ 全部符合標準 → [草稿] → 業務自行 [送出] → [已送出]
      │
      └─ 觸發審核條件 → [草稿] → 業務 [申請審核] → [待審核]
                                          │
                          管理者 [核准] ──┤
                                          ├── [已核准] → 可輸出 PDF
                          管理者 [退回] ──┘
                                          └── [退回修改] → 業務修改重送
```

**報價單狀態流：**
`草稿` → `待審核` → `已核准` → `已送出` → `已確認(客戶簽回)` → `已完結`
↑ 任一狀態可 → `已取消`

## 十四、特殊欄位規則（已確認）

### 折讓（Discount）
- **不在標準建單表單中顯示**
- 業務需勾選「申請特殊折讓」才展開填寫欄位
- 勾選後自動觸發管理者審核
- 折讓以**金額**為單位（NT$），非百分比

### 間接成本

| 項目 | 規則 |
|------|------|
| 管銷分攤率 | 固定 **10%**（= 稅前合計 × 10%），**鎖定，不可手動改** |
| 管銷分攤率調整 | 需填寫「調整申請」送管理者核准後才能修改 |
| 運輸物流費 | 手動填入（NT$ 金額） |
| 安裝施工費 | 手動填入（NT$ 金額） |
| 差旅費 | 手動填入（NT$ 金額） |
| 保固預估費 | 手動填入（NT$ 金額） |
| 其他費用 | 手動填入（NT$ 金額） |

### PDF 預覽
- 點擊「預覽」→ **在瀏覽器同頁面右側或新分頁開啟 PDF**（iframe 嵌入）
- 支援兩個預覽按鈕：「預覽對外版」/ 「預覽內部版」
- 確認後點「下載 PDF」或「存檔至 exports 資料夾」

### 現金流水位計算方式

> 本系統不直接連銀行帳戶，以「估算」方式呈現現金流趨勢

```
現金流水位（估算）= 已確認收款總額 − 已付採購款總額
本月預期收入     = 本月到期應收帳款
本月預期支出     = 本月到期應付帳款
```

水位以視覺百分比顯示，並標注：「此數字為系統估算，以實際銀行帳戶為準」
