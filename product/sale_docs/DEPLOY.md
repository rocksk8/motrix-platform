# 安裝與上線注意事項

> 下文的 `<安裝目錄>` 請換成貴公司實際的安裝資料夾。本文件只回答一件事：**哪些功能不設定就不會動，而不動的時候看起來像什麼。**

---

## 一、兩個對外連線的開關（預設都是關的）

| | 不設定會怎樣 | 設定了會怎樣 |
|---|---|---|
| **標案雷達** | 不會去抓標案。畫面上有頁面、有搜尋條件，**就是不會有新標案進來** | 每天在設定的時段，連到政府電子採購網抓公告 |
| **地圖／距離** | 地址定位不到 ⇒ 地圖上沒有點、距離全部是空白 | 把地址送到 OpenStreetMap 換成座標 |

**打開它們＝這台機器會主動連到外面的網站。** 預設關著，是為了讓一台裝好的機器不會在沒有人知道的情況下對外連線。
要打開，在啟動服務時加上環境變數（寫進 `<安裝目錄>\backend\autostart.bat`）：

```
set MOTRIX_TENDER_RADAR=1     打開標案雷達
set MOTRIX_GEO=1              打開地址定位
```

### 改完之後要重啟「外面那個迴圈」

`autostart.bat` 是一個**正在執行中的迴圈**。改了檔案，正在跑的迴圈仍然用舊內容。
⇒ 請在「工作排程器」找到「MOTRIX ERP Server Autostart」→ 結束 → 執行（或直接重新開機）。
**只重啟 uvicorn 沒有用**——重新把它拉起來的，正是那個還在用舊內容的迴圈。
沒做這一步的症狀是：服務正常、畫面正常，**雷達安靜地不掃、地圖上沒有點**，而那跟「今天沒有新標案」看起來一模一樣。

### 怎麼確認它真的開了

- 標案雷達頁上方沒有「總開關目前是關閉的」那一行 ⇒ 雷達開了
- 地圖頁沒有「地理查詢未啟用」那一行 ⇒ 定位開了

## 二、標案雷達的抓取與寄信時段

系統內建預設：抓取每天 9、12、15、18 點；寄信每天 18 點（一天一封彙總信）。
那是「還沒有人設定過」，不是「您設定過的值」。建議上線後到標案雷達頁按一次「儲存」，把要的值真的存進去。
寄信時段留空＝完全不寄信（標案照樣抓、照樣出現在畫面上）。

## 三、要指派的權限

在**使用者管理**裡，「業務」群組下有「標案雷達」與「地圖」兩個權限，管的是**側邊欄看不看得到**。
地圖的資料本身只要求登入，別把它當成安全牆。只給地圖、不給雷達的人打得開地圖，只是地圖上不會有標案（畫面會明講）。

## 四、辦公室地址

**公司資料設定 → 基本資料 → 辦公室地址**。不填的話，地圖與標案清單上的「距離」全部是空白（畫面會寫「尚未設定辦公室地址」）。
距離是直線距離，不是行車距離；標案地點目前只到縣市層級。

## 五、地圖底圖

地圖頁預設只顯示清單，完全不連外網；按「開啟地圖（需要網路）」才會載入底圖。
OpenStreetMap 對瀏覽器的圖磚請求有用量限制，被擋時會回一張寫著封鎖字樣的圖，**看起來像地圖正常運作**。那不是地圖壞了；清單與距離不受影響。

## 六、地圖第一次打開只會看到少數幾個點——這是正常的

地址要變成座標，得先問 OpenStreetMap，而對方**每秒只接受一次查詢**。
系統每次打開地圖只花幾秒去查還沒查過的地址，其餘顯示「還有 N 個地址這次來不及定位」，旁邊有「繼續定位」按鈕。
查到的結果永久存在資料庫，那個數字只會往下掉。**按「繼續定位」，或是就這樣用**，都不會有損失。
判斷依據是那句「還有 N 個…」：有 ⇒ 正常，只是還沒查完；沒有那句話而點還是很少 ⇒ 回頭檢查第一節與第四節。

## 七、資料庫會自動升級

更新後首次啟動會自動跑資料庫升級步驟（只新增欄位與資料表，不修改也不刪除既有資料）。
升級是自動的，不需要做任何事，但**更新前請照平常的習慣留一份備份**。

## 八、備份告警信

「備份太久沒跑」的告警會寄信通知。如果備份曾經成功、後來停了，更新後可能收到一封告警——那是一個一直存在的問題，現在才被通知。

## 九、多據點（分公司）

公司地址會成為第一筆據點「總公司」。只有一個據點時，畫面與行為和單一公司完全一樣。
分公司的請款單目前**仍然印總公司的匯款帳號**（據點可各自填銀行欄位，但 PDF 尚未讀取）：新增分公司後開請款單，請人工確認帳號。

---

## 更新不會自動做的事

- 不會自己打開任何對外連線（要設環境變數）
- 不會自己指派新權限（要在使用者管理裡勾）
- 不會自己填辦公室地址
- 打包與部署由貴公司管理者執行
