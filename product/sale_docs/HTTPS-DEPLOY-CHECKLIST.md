# HTTPS 啟用步驟清單

> 適用：把系統從明文 HTTP 改成 HTTPS（自簽憑證，適合內網）。全程約 15–20 分鐘，建議選離峰時段（會重啟一次服務）。
> 下文的 `<安裝目錄>`、`<伺服器 IP>` 請換成貴公司實際的安裝資料夾與伺服器固定 IP。

## 前置確認

- [ ] 確認目前在**伺服器**上（不是個人電腦），且已用系統管理員能寫入 `<安裝目錄>` 的帳號登入
- [ ] 已依日常更新流程把程式更新到最新版（憑證工具隨程式一起更新，不需要另外處理程式碼）

## 步驟

1. **下載 mkcert.exe**
   - 前往 <https://github.com/FiloSottile/mkcert/releases>，下載 Windows amd64 版本
   - 改名成 `mkcert.exe`，放進 `<安裝目錄>\backend\tools\`（跟 `https_setup.ps1` 同一層）
   - 不需要安裝、不需要系統管理員權限

2. **執行憑證產生腳本**
   ```powershell
   powershell -ExecutionPolicy Bypass -File "<安裝目錄>\backend\tools\https_setup.ps1" -Host2 <伺服器 IP>
   ```
   - `-Host2` 填伺服器的固定 IP（憑證會綁定這個位址）；IP 之後有變動要重跑一次
   - 執行完會在 `backend\certs\` 產生 `cert.pem` / `key.pem`（只存在這台伺服器，不會隨更新包散佈）

3. **重啟服務**
   - 用 `restart.bat`（偵測到 `certs\` 存在時會自動改用 HTTPS 啟動），或重新開機讓開機自動啟動接手

4. **驗證**
   - [ ] 瀏覽器開 `https://<伺服器 IP>:666`，出現「連線不安全」警告是**預期行為**（自簽憑證、沒裝根憑證），點「進階」→「繼續前往」
   - [ ] 能正常登入、頁面功能正常
   - [ ] 舊的 `http://` 網址連不上是預期行為（服務已改成只監聽 HTTPS）
   - [ ] `backend\logs\server.log` 的啟動訊息有帶 SSL 參數

5. **更新書籤與通知設定**
   - [ ] 桌面捷徑、瀏覽器書籤、內部文件裡的網址，`http://` 改成 `https://`
   - [ ] 用最高管理員登入 → 通知設定 → 「系統網址」改成 `https://<伺服器 IP>:666`（既有設定不會自動變更，通知信裡的連結會繼續指向 http 直到手動改這裡）
   - [ ] 通知同事：第一次連線看到「不安全」警告是正常的；若想免警告，可把伺服器的根憑證安裝到各電腦（`backend\tools\fetch_root_ca.ps1`）

## 如果出問題想回退

- 把 `backend\certs\` 資料夾整個搬走（或刪除），重啟服務——啟動腳本偵測不到憑證就會自動退回明文 HTTP，不需要改任何程式碼
